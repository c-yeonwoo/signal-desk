# 단타 진입 비교 · 검수 기록

- `desktop.png`, `mobile.png`: 실제 새 컴포넌트 HTML/CSS/JS와 보존된 연구 요약의 격리 렌더.
  기본 데스크톱과390px 뷰포트, 본문16px, 모바일 수평 넘침 없음.
- `missing.png`: 같은 격리 서버에서 원천 결측을 합성해 null·판정 보류·누적선 중단 확인.
  실제 원천 결손 보고가 아니며 수익률0으로 대체하지 않는다.
- `error.png`: 같은 서버의 합성503. 오류 설명과 새로고침 버튼의 재사용 확인.
- 실제 브라우저에서 사건별 펼침·연구 가정 펼침·새로고침을 확인했다.
  JS 실행 검사는 HTML 방어·null 전파·API 실패/미배포·숨긴 탭 요청 중지를 별도로 확인한다.
- 수집기·API 키·계좌·운영 앱 서버를 로드하지 않는 HTTP 서버에서 검수했다.
  운영 배포 확인과 이 격리 화면 검수는 다른 증거다. 모든 캡처는 생성 이미지가 아닌 브라우저 스크린샷이다.
- 두 번의 묶음 캡처 뒤 새 화면 탐색을 멈췄다. 활성 디자인 훅에서 새 CSS의 기계적 지적은 없었다.
  기존 `.impeccable/design.json`이 DESIGN.md보다 오래됐다는 경고는 범위 밖으로 남겼다.
- 전용 Impeccable 역할이 없어 새 컨텍스트 일반 리뷰어로 대체했다. 마감 판정 `ship`:
  고정 비교·손실·미채택·결측 구분의 한정 컴포넌트 범위, 전체 관리자 품질 인증은 아니다.
- 독립 코드 리뷰는 확신 높은 차단 결함0. 리뷰어는 실제 브라우저나 연구 재실행을 하지 않았다.

기존 DESIGN.md와 사이드카를 이 국소 확장 때문에 재작성하지 않는다. 디자인 완료는 수익성 개선으로 세지 않는다.
