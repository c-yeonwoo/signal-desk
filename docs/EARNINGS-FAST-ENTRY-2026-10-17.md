# 실적 발표 직후 진입 · 원천 확보와 실행 계약

## 가격 결과를 보기 전 고정하는 범위

#758의 두 번째 정규장 진입 실패는 발표 직후 진입의 검증이 아니다. 이번에는 공개 시각, 그 뒤 주문 가능한 호가와 수량, 실제 계좌 비용을 먼저 확인한다. 기존 2024/2025년 결과는 이미 보았으므로 새 독립 확인 표본이라고 부르지 않는다. 등록 보호 구간인 2026-08-04 이후 가격은 탐색에 사용하지 않는다.

첫 접근 검사는 AAPL의 2023-02-02, 2025-01-30 공식 발표 원문과 각각 다음 정규장 2023-02-03, 2025-01-31 09:30~11:00 ET의 역사 분봉이다. 가격 수익은 계산하지 않고 날짜·행 수·권한·원천 종류만 확인한다. KIS의 공식 분봉 API에서 KEYB는 다음 조회의 시간 커서다. 과거 날짜를 넣었다는 이유만으로 그 날짜의 봉이 반환됐다고 간주하지 않는다. Alpha Vantage는 기존 키의 역사 분봉 권한을 한 번 검사한다. 신규 결제·가입·실주문·운영 설정 변경은 하지 않는다.

자료가 확보되면 가격 조회 전에 별도 사건 목록을 동결한다. 기존 고정 8개 회사, 2022년 개발·2023년 확인, EPS 예상 대비 5% 상회라는 가설을 사용하되 예상치의 당시 버전과 GAAP/조정 기준도 확인해야 한다. 이 문서의 접근 검사만으로 백테스트 표본 동결을 대신하지 않는다.

## 두 진입 경로를 구분한다

1. **공개 직후**: 원문 공개와 분석 입력 도착 중 늦은 때 + 공개 시각의 불확실성 + 처리·주문 지연 30초 이후 첫 유효 매도호가에 제한된 수량으로 진입한다. 분 단위 공개시각에는 60초 불확실성을 더하며, 날짜만 있으면 이 경로는 계산하지 않는다. 시간외 매매 권한·지원 주문·거래 장소를 확인한다. 60분 뒤 첫 유효 매수호가에 청산한다. 추가 60초 지연·절반 체결·미체결을 스트레스로 둔다.
2. **첫 정규장 초반**: 공개 직후 경로와 별개다. 공개와 분석이 완료된 뒤 처음 오는 정규장 시작 + 60초 이후 호가로 진입하고 60분 후 청산한다. 휴장·조기마감은 거래소 달력으로 결정한다. 개장 분봉의 시가를 이미 체결 가능한 가격으로 간주하지 않는다.

호가의 시각·통화·거래 장소·bid/ask와 수량·거래 상태가 필요하다. 분봉 OHLCV만 있으면 가격 반응의 탐색은 가능하지만 실제 ask 진입/bid 청산, 지정가 대기열·미체결을 인증할 수 없다. 오늘의 호가나 일봉을 과거 호가 대신 사용하지 않는다. 순간 호가도 체결 보장은 아니므로 결과는 실행 모델이며 독립 모의 관측 전 실주문 적격은 false다.

## 비용과 채택

브로커의 공개 기본 수수료와 실제 연결 계좌의 할인·최소 수수료를 구분한다. 실제 정산 자료의 적용 기간·채널·통화·매수/매도 수수료·제비용이 확인되지 않으면 `account_costs_unverified`다. 미래의 현재 요율을 2023년 실제 비용이라고 소급하지 않는다. 호가 스프레드는 bid/ask 가격에 이미 들어가므로 수수료와 중복 가산하지 않는다. 기존 45/75/120bp는 가정이지 실측 비용이 아니다.

필수 입력이 빠지면 수익률은 null, 결과는 `blocked_missing_execution_sources`이며 전략 성능을 채택/기각하지 않는다. 완전한 사건 자료가 생긴 뒤 전 사건·동일 시각 시장·현금 대조, 지연·비용·체결 스트레스, 종목/분기 집중도와 현금 제약을 포함한 계획을 별도로 동결한다. 데이터 부족을 0% 수익이나 0건 성공으로 바꾸지 않는다. 등록 문턱·가중치·기존 주문은 바꾸지 않는다.

### 실제로 확인한 대체 원천과 원인

- **Alpha Vantage**: 기존 키의 2023-02 `TIME_SERIES_INTRADAY`, `adjusted=false`, `extended_hours=true`는 `Information: This is a premium endpoint`를 반환했다. [공식 문서](https://www.alphavantage.co/documentation/#intraday)와 일치한다. 유료 분봉을 사더라도 과거 NBBO 호가가 자동 확보되는 것은 아니다.
- **KIS 실전 도메인**: 분봉 두 날짜는 HTTP 500 / **EGW02004: 모의투자 앱키로 실전 도메인 호출 불가**다. 같은 키의 과거 일봉 대조는 HTTP 200 / MCA00000이었다. 일봉 성공을 분봉 권한 증거로 읽지 않는다. 오류 본문을 보존한 추가 진단으로 원인을 확인했으며, 기존 앱의 `None` 응답만으로 역사 봉이 없다고 단정하지 않는다. 키·환경 설정은 바꾸지 않았다.
- **KIS 모의 도메인**: 두 날짜 모두 HTTP 200 / MCA00000이지만 `output2=[]`. 요청 날짜의 봉은 0행이다. **실전 키로 같은 역사가 제공되는지는 미확인**이다. 이 문제와 별개로 토스에서 분봉을 확보했으므로 분봉 부족을 전체 중단 사유로 쓰지 않는다.
- **Alpaca**: [공식 FAQ](https://docs.alpaca.markets/us/docs/market-data-faq)는 15분보다 오래된 SIP 자료의 무구독 조회 경로를 설명한다. [역사 호가 API](https://docs.alpaca.markets/us/reference/stockquotes-1)는 bid/ask를 조회할 수 있다. 현재 로컬에 키가 없어 요청하지 않았다. 무료 IEX 단일 거래소를 통합 SIP 호가로 대신하지 않는다. 새 계정 생성·약관 동의·결제는 하지 않는다. **우선 필요한 사용자 조치는 Alpaca 데이터 키 제공 또는 동등한 역사 호가 파일 제공이다.** 키 권한·기간·시간외 범위를 실제 검사한 뒤 비용 발생 없이 가능한 만큼 진행한다.
- **Kibot 무료 표본**: [공식 안내](https://www.kibot.com/free-historical-intraday-data.html)의 분봉은 IBM/OIH 최근 3개월, 호가 표본은 IVE/WDC 최근 1개월이다. 이번 8개 회사의 2022/2023 확인 기간과 다르고 최근 자료는 보호 구간을 침범할 수 있어 내려받지 않았다. 표본에 맞춰 회사·기간을 사후 교체하지 않는다.
- **공개 시각 보충**: [NVIDIA 배포 원문 예시](https://www.globenewswire.com/news-release/2023/05/24/2675692/0/en/NVIDIA-Announces-Financial-Results-for-First-Quarter-Fiscal-2024.html)는 2023-05-24 16:20 ET를 표시한다. 웹 문헌 확인과 달리 이번에 직접 저장하려던 별도 2월 원문은 HTTP 403이어서 전체 표본의 검증된 시각 원장에 넣지 않았다. 한 회사의 배포 시각을 모든 기업의 발표 시각으로 일반화하지 않는다.
