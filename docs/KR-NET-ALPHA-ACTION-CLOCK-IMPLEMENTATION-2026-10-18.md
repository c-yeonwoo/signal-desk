# 기업행사 날짜 처리 구현과 원천 범위 검수

2026-10-18 · 후보 `kr-separated-net-alpha-h5-v2` · [고정 명세](KR-NET-ALPHA-ACTION-CLOCKS-2026-10-18.md).

**날짜·정정 처리와 원천 범위 감사 구현을 완료했다. 실제 자료 검사는 `blocked_data`이며 학습·보정·210경로 백테스트는 실행하지 않았다.** 현재 자료로 전략을 채택하거나 기각할 수 없어 `not_evaluable_data_gate`로 남긴다.

## 구현한 처리

`research_action_clocks.py`는 경제 사건의 구성요소와 필드별 출처·공개 정밀도·정정을 해석한다. 명시적 정정 연결만 적용하고, 수정하지 않은 필드는 원래 출처와 가용시각을 유지한다. 같은 값의 재확인은 최초 가용성을 보존하며, 상충한 정지 경계는 거래 가능한 것으로 처리하지 않는다. 수집 순서와 공개 순서도 구별한다.

v2 입력은 분할의 **가격 적용 세션**으로 과거 가격·거래량을 연결하고, 실제 발행주식수 전환과 검수된 수량을 대조한다. 법적 효력일이나 예정 일정만으로 가격 단위를 바꾸지 않는다. 단순 분할로 확인되지 않은 주식배당·감자 등은 계산을 보류한다. 원시 가격은 보존하며 단위 ID와 전환 근거를 별도로 출력한다.

결과 라벨은 권리 귀속 경계를 사용한다. 배당락 개장 매수자는 해당 권리를 받지 않고 같은 개장에 매도한 이전 보유자는 권리를 유지한다. 미교부 주식배당은 거래 잔고로 바로 늘리지 않으며, 날짜만 있는 교부를 그날 개장 전에 완료했다고 간주하지 않는다. 합병 후속 주식에도 교부·거래 가능 근거를 요구한다. 권리 계상·금액 정정·교부는 별도 기록으로 처리해 재생 때 중복 반영하지 않는다.

`effective_at`만 있는 기존 경제 사건 입력은 거부한다. 기존 정지 구간 입력은 호환한다. 원문 해시·본문 위치·공개 근거·공식 과거 ISIN/보통주 연결과 부모/v2/날짜 명세 해시를 함께 검사한다. 이 모듈은 연구 경로에서만 사용한다.

5개 회사의 공식 원문 9개를 **9개 assertion**으로 연결했다. 기존 아시아나 정지 사실 1개는 유지했다. 날짜별 공식 기본정보 원문으로 ISIN·주식종류를 확인했으며, 현재 회사명이나 검색용 회사 코드로 대신 연결하지 않았다.

## 준비 검사 결과

새 증거 묶음을 넣고 고정된 전체 날짜를 재검사했다. 충분한 이력이 있는 잠정 U에서 285개 증권의 의존 구간을 합쳐 **입력699·결과989, 총1,688개 범위**를 만들었다. 이들은 학습585·보정459·평가644범위다. 각 범위의 입력10종류/결과11종류·정정 근거를 검사했으나 현재 인증서는0개다. 보고서의 `source_unavailable`은 **필요한 범위 증명을 현재 묶음에서 제공할 수 없음**을 뜻하며 모든 원천 사이트가 접속 불가라는 뜻이 아니다.

범위 미인증은140,447종목일이다. 별도 가격·거래량 이력 계산 불가4행(017670/2021-11-29, 009830/2023-03-31, 003620/2023-04-28, 010060/2023-05-30)도 유지했다. 확인된 진입 불가는 학습9·보정3·평가10행이며 수익률0으로 바꾸지 않았다. 결손 종목이나 평가일을 지워 통과시킨 날짜는 없다.

KIND 접수일 기준3,435행은 일부 권리락·배당락·기준가격 공지다. 11종류의 효력 기간 전수 목록이나 정정 완료 증명이 아니다. 공식 [주식권리일정정보](https://www.data.go.kr/data/15059609/openapi.do)와 [주식발행정보](https://www.data.go.kr/data/15043423/openapi.do) 안내를 추가 보존했다. 권리일정 API는 무료·일간 갱신으로 안내하지만 과거 보존 범위는 명시하지 않는다. 로컬의 알려진 서비스키 변수7개에서 키가 확인되지 않았고, SEIBro API 포털 직접 요청은 연결 종료됐다. Railway 키 존재 여부는 이 로컬 검사로 판단하지 않는다. 새 API의 과거 응답·날짜 의미·정정 범위를 실제 확인하기 전까지 범위 인증으로 사용하지 않는다.

누적 요청은 가격/메타데이터 **810/1,200**, 행사 **160/400**이다. 요청 예산 소진이나 미래 거래일 대기가 중단 이유가 아니다. 다음은 공식 권리 일정/발행 원천에 대한 접근과 실제 범위 검수다. **Sol high로 계속 가능**하며, 동일한 사실의 공식 원문 충돌이나 명세 밖 정산 조건이 나타나기 전 모델 전환은 필요하지 않다.

## 보존과 재현
