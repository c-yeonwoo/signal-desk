## 결론부터

다음 질문은 “예측값을 얼마나 낮출까”가 아니다.
**“같은 조건의 과거 사례에서 비용을 낸 뒤 얻은 이익과 입은 손실을 각각 학습하면,
현재의 평균 수익 회귀보다 실제로 돈이 남는 종목을 잘 고르는가?”**다.

새 후보는 작은 비선형 모델 두 개로 이익 기여와 손실 부담을 따로 추정한다.
차이는 예상 순수익이다. 동일한 모델 종류로 순수익 하나만 예측하는 대조를 함께 둬,
모델 교체 효과와 목표 분리 효과를 구분한다. 모델 두 개가 독립된 전문가의 합의나
두 배의 증거를 뜻하지는 않는다.

이번 대상은 **국내 신규 진입의 다음 시가→5세션 뒤 시가**다. 보유 갱신·재진입·장중
추격까지 한 번에 바꾸지 않는다. 연구 계좌에서는 목표와 일치하게 h5에 청산한다.
운영 보유·매도 정책에는 연결하지 않는다. 선정력도 입증하지 못한 상태에서 또 다른
보유 최적화기를 붙이는 순서를 중단한다.

### 이름만 비용 예측으로 바꾸지 않기

고정 비용을 빼는 `y_net = a*y_gross+b`를 같은 절편 있는 선형 Ridge에 넣으면,
동일 전처리·벌점 아래 계수와 절편이 같은 비율로 변하고 순위는 그대로다(a>0).
“비용 후 수익을 학습했다”는 이름만으로 선정력이 생기지 않는다.

승률만 높여도 안 된다. 가령90% 확률로1%를 얻고10% 확률로15%를 잃으면,
비용 전 기대수익부터−0.6%다. 반대로 손실을 무조건 크게 벌주는 목표는 현금만
고르게 만들 수 있다. 이번에는 별도의 손실 배수·안전마진·시장 veto를 추가하지 않는다.

## 2. 예측 목표 — 확률이 아니라 이익과 손실의 금액 효과

판단일 t의 입력만 사용한다. `e=t+1`, `x=t+6`은 거래 세션 인덱스다.
원시 시가 수익 `r=O_x/O_e−1`에 왕복120bp 가정을 적용한다.
`c=0.006`은 편도 비용 가정이며 실제 증권사 비용이나 호가 인증이 아니다.

```text
n = (1+r) × (1−c)/(1+c) − 1
g = max(n, 0)          # 순이익 기여, 손실 사례에서는0
l = max(−n, 0)         # 순손실 부담, 이익 사례에서는0

G(x) ≈ E[g | 판단 시점의 특성 x]
L(x) ≈ E[l | 판단 시점의 특성 x]
예상 순수익 μ_net = G(x) − L(x)
```

G는 “오른 경우의 평균 수익”이 아니라 **손실 사례의0도 포함한 무조건부 기대 기여**다.
L도 동일하다. 따라서 여기에 상승/하락 확률을 다시 곱하지 않는다.
예를 들어 G=2.0%, L=2.8%면 예상 순수익−0.8%다. 좋은 사례만 설명하며
양수 예측을 남기는 대신, 예상 손실 부담을 같은 단위로 드러낸다.

이 항등식 자체가 새 정보를 만들지는 않는다. 제대로 추정할 수 있다면 단일 조건부 평균과
같은 기대값이다. **서로 다른 비선형 관계로 이익과 손실을 추정하는 유한 표본의 학습 방식이
더 나은가**가 검증 대상이다. 실패하면 이 분해도 채택하지 않는다.

예측 G/L/μ는 보장 수익·상승 확률·신뢰구간이 아니다. 손실 L은 최악 손실도 아니다.
평균 손실 부담과 드문 큰 손실을 따로 보고한다. 종가 기반 h5 모델로 발표 직후 호가나
당일 단타 타이밍을 맞췄다고 주장하지 않는다.

### 원천 한계

라벨은 기존 `label_at`의 가격·주식수 경로 관문을 그대로 사용한다. 미확인 시가·주식수
변화는 null이다. 주식수 불변만으로 배당·모든 기업행사 없음이 인증되지는 않는다.
따라서 명칭은 **가정 비용 후 가격 손익**, 검증된 총수익이 아니다. 새 라벨을 임의로
0이나 최악 손실로 채우지 않는다. 익절·손절이 어느 시각에 먼저 났는지도 일봉으로 만들지 않는다.

## 3. 모델과 입력 — 후보 하나, 탐색 없음

기존14특성·동일 날짜별 투자 가능 집합을 유지한다. 이번 실패는 그14개 모두가 무가치하다는
결론이 아니라 현재 결합 방식이 단순 기준을 못 이겼다는 결과다. 새 특성·뉴스·LLM·외부
수집을 동시에 추가해 무엇 때문에 좋아졌는지 모르게 만들지 않는다.

선택 모델은 연구 전용 `HistGradientBoostingRegressor` 두 개다. 각각 G와 L을 학습한다.
비음수인 연속 기여값에 Poisson deviance를 **평균 추정 손실함수**로 사용한다.
주식 수익이 Poisson 분포라는 가정이나 분산=평균의 확률모델로 해석하지 않는다.
로그 링크로 출력이 음수가 되지 않는다. 라이브러리의 손실 정의와 재현성을 테스트한다.

| 항목 | 고정값 |
| --- | --- |
| target 단위 | `100*g`, `100*l`(%p 단위), 예측 시100으로 나눠 수익률 분수로 반환 |
| loss / learning_rate / max_iter | `poisson` /0.05 /50 |
| max_depth / max_leaf_nodes / min_samples_leaf |2 /4 /200 |
| max_bins / l2_regularization |32 /1.0 |
| early_stopping / random_state |false /20261023 |
| 입력 | 원14개 + 기존14결손 지시자. 해당 fold의 학습 중앙값·평균·scale·clip8 재사용 |
| 날짜 가중 | 각 날짜 총가중 동일. N학습행, D학습일, n_t행이면 `N/(D*n_t)`, 전체 평균 가중1 |

임의 행 분리 early stopping은 금지한다.200행은200개의 독립 시장 관측이 아니다.
학습의 실제 날짜 수·라벨 만기·종목 수를 함께 남긴다. 두 개의 깊이2 나무 연쇄가 조건별
반응 차이를 표현할 여지는 있지만 작은 날짜 표본에서 과적합할 위험도 있다.
최적 깊이·반복 수·손실함수 검색은 없다.

전처리는 원Ridge와 동일 계약으로 각 학습 구간에만 적합한다. 원 구현의 중앙값·평균·표준편차는
학습 행 기준이며 날짜 동일 가중 통계가 아니다. 이 정의를 바꾸지 않고, 트리에 전달하는
학습 손실의 sample_weight는 위 식으로 별도 명시한다.
결손 지시자는 이전대로 유지한다. 신규 종목의 미래 라벨 상태는 입력으로 넣지 않는다.
어느 head의 학습 목표가 전부0이면 그 head는 상수0으로 고정하고 실제 fit 횟수를 줄인다.
양쪽 전부0이면 무거래/정보 없음으로 종료한다. G/L head의 음수나 모든 팔의 예측 NaN·무한은
실행 결함이지 클리핑해 통과시킬 값이 아니다. μ_net·단일 net tree·Ridge의 음수는 정상이며
신규 진입하지 않는 근거다.

**전부2024년이다.** 모델별 train cutoff/마지막 라벨 시각/전처리 해시를 보존한다.

각 fold의 부족을 이유로 날짜를 확장하거나 뒤의 모델을 앞 평가에 쓰지 않는다.
4개 fold 결과로5번째 모델의 파라미터·head·비용·문턱을 고르지 않는다.
최종 모델도 같은 고정 알고리즘을 전체 허용 학습행에 적용할 뿐이다.

최대 fit는 `(2 head + 단일 tree + Ridge) ×5학습구간 =20회`다.
모멘텀은 fit0. 날짜 순서의 개발 실행 묶음1회, 원천 요청0회다.
이미 재현한 원Ridge 산출물을 재사용하면 해시·조건 일치를 기록하고 실제 fit 수를 낮춘다.
하이퍼파라미터 탐색·후보 자동 생성·새 자료 확보·수일 관측 대기는 이번 범위 밖이다.

**이 기간은 모두 이미 열람한 개발 자료다.** 시간순 fit은 미래 라벨 누수를 막지만,
설계자가 과거 실패를 본 사실까지 지우지 않는다. 이 설계로 독립 검증 완료·실전 승격은
낼 수 없다. 보호 표본을 열거나 기존 등록 실험의 기준을 낮추지도 않는다.

## 5. 선정력과 거래 성과를 분리해서 확인

### A. 현금으로 도망가도 통과하지 못하는 선정 진단

4개 내부 fold에서 네 팔 모두 문턱 없이 상위6을 뽑는다. 동일 금액·h5 코호트,
75/120bp·5시작 위상으로 **160계획 경로**다. 기존 코호트 계산기를 재사용한다.
월별 코호트를 연속 계좌처럼 이어 붙이지 않는다.

두 head의 선정 순위 동점은 종목코드 순이다. 모멘텀을 새 tie-break로 붙이지 않는다.
각 날짜 G/L/μ, 상위6의 실현 이익 기여·손실 부담, 선택하지 않은 집합의 분포를 남긴다.
known-only 분석은 분모와 결손을 표시한 기술통계이며 전체 모집단 성과로 부르지 않는다.
예측오차 감소·손실 head 증가만으로 합격시키지 않는다.

두 팔의 후행 비교는 **그 두 팔**의 선정 라벨이 모두 있을 때만 수치가 있다.
후행값 없는 종목을 선정에서 빼지 않는다. 비교별 공동 결손과 팔 자체 완결을 따로 기록한다.
네 팔 전부가 완전해야 하는 합격 지표와 두 팔만 비교 가능한 설명 지표를 혼동하지 않는다.
앞선52개 결손을 해결했다고 주장하지 않으며 여기서 같은 원천 검수를 재개하지 않는다.

이 내부 진단은 부족한 어느 월을 삭제하는 용도가 아니며, 매월 반드시 이겨야 한다는
#816의 판정을 소급 변경하지도 않는다. **새 후보의 주 판정은 아래 고정 계좌 비교**다.
내부 결과는 전부 공개하고, 안정성에 반하는 결과가 있으면 지지 범위를 축소한다.

### B. 실제 주식수·비용을 포함한 신규 진입 계좌

10/2–12/11의49일, 위상 p는 판단일 목록 `[p::5]`다.
초기자금1,000만원, 공매도·차입 없음, 종목별 예산 최대1/6, 최대6종목이다.
세 예측 팔은 각자 상위6 중 `μ_net>0`만 진입한다. 통과 못한 자리를7위로 채우지 않는다.
μ=0은 현금과의 기대 순수익 경계이지 결과를 보고 찾은 문턱이 아니다.
모멘텀은 항상 상위6에 같은 슬롯 예산을 부여한다.

각 진입은 t 종가에 주문을 고정해 e 시가에 제출하고 x 시가에 청산한다.
청산은 다음 날 예측이 나빠졌기 때문이 아니라 **학습한 h5 목표를 채점하기 위한 일정**이다.
5세션 뒤 다음 코호트와 같은 종목이어도 연구에서는 매도·재매수 비용을 모두 부담한다.
네 팔 모두 동일하다. 순수량 보유 유지의 가치를 검증한 실험으로 부르지 않는다.

기존 `ExecutionBook`의 정수 수량·종가+1% 매수 한도·직전 거래량1% 참여율·T+2 원장을
재사용한다. 이번 후보용 예측 어댑터와 만기 주문 일정을 연구 파일에서만 구성한다.
판단일의 **각 계좌 자신의 NAV**를6등분한다. 주문량은 t에서 확정하며 다음 시가를 보고
늘리지 않는다. 매도 우선, 미정산/미체결 잔량의 자본을 중복 투자하지 않는다.
코호트별 비용 후 라벨은 분석용이고, 실제 장부는 체결 때 비용을 한 번만 차감한다.

75bp·120bp·75bp 매수절반·75bp 제출1세션 지연의4시나리오에서 각각 계좌를 재생한다.
학습·μ·진입 조건은 모두120bp 기준 그대로다. 시나리오에 맞춰 재학습하지 않는다.
지연 조건은 진입/만기 주문 제출을 모두1세션 늦춰 e+1→x+1로 맞추고,
주문 시점·가격 한도·수량의 미래 참조는 추가하지 않는다. 절반 매수는 가능한 정수 수량을
반으로 내림한다. 미체결 매수는 취소, 미체결 만기 매도는 기존 최대5세션 재시도한다.
정지·청산 실패·단위 미검수는 최종 수익null이다. 가격 확인 꼬리는12/31까지다.

기존 `ExecutionBook.submit`은 새 판단에 pending을 교체한다. 이를 그대로 반복 호출해
만기 매도의 재시도 횟수를 초기화하지 않는다. 연구 어댑터에서 코호트/원주문 ID,
최초 종가 주문 생성일, 최초 체결 시도 예정일(original due_on), 잔량,
**original due_on+5정규세션의 절대 종료일**을 보존한다(최초1회+재시도5회).
original due_on은 시나리오 지연을 반영한 첫 시가 시도일이며 전일 종가 생성일이 아니다.
새 코호트는 이전 만기 주문을 취소·갱신하지 못한다.
이전 코호트의 같은 종목 잔량이 남으면 해당 종목 새 매수는 취소하고 다음 후보로 대체하지
않는다. 다른 종목도 남은 보유의 슬롯·자본을 사용하지 못한다. 거래량 한도 때문에 처음부터
주문하지 못한 잔량 역시 사라진 것으로 처리하지 않으며, 기한 내 전량 청산을 입증하지
못하면 미완결이다. 기존 공통 실행 코어의 기본 동작은 변경하지 않는다.

마지막 지연 만기의 최초12/20 매도는 재시도가12/30까지 갈 수 있다. 이때 T+2 결제는
2025/1/3이다.12/31 안에 체결을 확인하고 보유·미체결 주문이0이면, **이미 확정된 결제
원장만** 마지막 T+2까지 달력으로 해소한다. 새 주문·가격 조회·평가 기간 연장이 아니다.
가격 손익은 마지막 체결에 확정하고 현금 이동을 수익으로 다시 더하지 않는다.
12/31 뒤 새 체결/보유 가격이 필요하면 자료 미달로 남긴다.

모델 목표는 모든 유효 시가쌍의 가상 왕복 수익이지 매수한도 충족 확률이 아니다.
실제 계좌에서 갭 때문에 진입하지 못했거나 수량이 줄어든 차이를 따로 귀속한다.
좋은 코호트 예측이 체결 불가로 계좌 이익이 되지 못하면 성공으로 세지 않는다.

현금 효과를 분리하기 위해 `momentum_same_slots`를 추가한다. 같은 위상·판단일에 후보가
사전에 고른 종목 수 k만 받아 모멘텀 상위k를 각각 자기 NAV의1/6으로 주문한다.
후보의 사후 체결 수나 미래 손익은 받지 않는다. 종목 위험·실제 체결 노출까지 같다는
뜻은 아니므로 **동일 위험 대조**라고 부르지 않는다. 사전 예산을 맞춘 선정 대조다.
후보가 전부 현금이면 이 대조도 현금이므로 선정력 근거가 되지 않는다.

네 기본 팔+슬롯 일치 모멘텀의5팔×5위상×4시나리오로 **100계획 계좌 경로**,
별도 현금 기준선0%다. 동일 원천의 단위·가격 문제가 어느 팔의 실제 보유·주문을 막으면
해당 위상/시나리오의 비교는 미완결이다. 팔별 장부는 남기되 부분 평균으로 합격시키지 않는다.
앞서39종목의 자료가 완전했던 사실을 새로운 선정 종목까지 확대 적용하지 않는다.

## 6. 판정 계약 — 돈을 남겼는지부터

아래는 이번 새 후보에만 적용한다. 기존 후보의 기각·등록 관문은 그대로다.
모든 비용 후 수익은 **기간 계좌 수익**이며 일 수익이 아니다. 기준선도 같은 새 h5 만기
정책으로 다시 비교하므로 #813~#815의 보유 갱신 계좌 수익과 숫자를 직접 차감하지 않는다.

1. **유효성:** 입력/시간/장부 불변식과 필수100계좌 완결. 원화 대사 오차1원 초과,
   미래 참조, 학습·예측 비유한값이면 `invalid_run`. 모형 효과를 해석하지 않는다.
2. **절대 수익:** 기본75bp와120bp 각각5위상 평균 순수익>0. 무거래 후보는
   `no_economic_edge`, 통과가 아니다.
3. **선정/구조의 추가 가치:** 두 비용 각각에서 후보의5위상 평균 수익이 Ridge,
   단일 net tree, 모멘텀, 슬롯 일치 모멘텀을 모두 초과한다. 현금 비중만 줄여 이긴
   것인지 A와 슬롯 대조로 따로 설명한다.
4. **위험:** 두 비용 각각 후보의 최악 위상 MDD가−10% 이상이며, 기본 세 거래 대조
   (Ridge/단일 tree/모멘텀)의 각 최악 위상 MDD보다 나쁘지 않아야 한다.
   기대수익 개선과 위험 개선을 같은 뜻으로 쓰지 않는다.
5. **체결 민감도:** 절반·지연 각각 완전한5위상 평균 수익>0이며 Ridge/모멘텀/슬롯
   일치 모멘텀의 평균보다 높고, 최악 MDD≥−10%. 시가 대용 실험이지 호가 검증은 아니다.
6. **평균 뒤의 실패 공개:** 위상별 순위,10월/11월/12월 부분월 손익, 종목별 이익·손실,
   비용·회전·미체결·평균노출, 사전20일 변동성·실현MDD를 함께 보고한다.
   집중 검사는 기본75bp의 각 위상에서 종목별 원화 순기여(거래비용 포함)를 계산해
   동일 종목끼리5위상 평균한 값으로 고정한다. 최대 양의 기여 종목1개(동점 코드순)를
   뺀 합이≤0이면 `concentrated_support`로만 기록한다. 이는 그 종목을 빼고 운용했을
   가상 계좌 수익이 아니다. 이미 다른 필수조건을 위반한 후보의 기각을 완화하지 않는다.

필수조건의 실패가 **완결 비교 단위에서** 확정되면 `rejected`다. 다른 결손이 있다고
그 반례를 지우지 않는다. 다만 일부 위상 손실 하나만으로5위상 평균 조건의 실패를
확정하지 않는다. 미완결이 남고 필수 실패를 확정할 수 없으면 `inconclusive_data`로
한 번 종료한다. 자동 수집·과거 기간 교체·결손 종목 제외로 이어가지 않는다.

모두 통과하더라도 최대 판정은 `conditional_development_support`다. 내부 fold에서
반복적인 역방향 결과 또는 높은 집중이 있으면 그 사실을 첫 줄에 함께 표시하고
일반화된 선정력 개선으로 표현하지 않는다.49일·중첩 위상은 독립 표본 수십/수백 개가
아니다. 부트스트랩으로 독립성이 생긴다고 주장하거나 p값으로 반복 탐색을 세탁하지 않는다.

**운영 적용은 이 설계에서 승인하지 않는다.** 독립 평가/현재 시점 재생 범위와 실제 비용을
별도 확정해야 한다. 이번의 완료는 유한 실험의 판정과 연구 코드 인계이며 수익성 완성이나
실계좌 수익 보장이 아니다. 자료 미달이면 그 결론으로 닫으며 며칠 기다리라는 작업을 만들지 않는다.

## 7. Sol 구현 인계와 비용

사용자가 설계를 확인하고 Sol로 바꾸면 다음 순서만 수행한다.

1. 원천·계획·코어 해시, Python/NumPy/새 연구용 scikit-learn 버전을 고정한다.
   새 의존성은 연구 전용으로 둔다. 운영 Docker/API의 설치·모델 호출은 바꾸지 않는다.
   기존 원 학습행 해시와 fold 경계를 한 번 확인한다.
2. `scripts/measure/kr_net_payoff_target.py`에 목표·모델·예측·두 평가 어댑터를 구현한다.
   필요하면 순수 연구 모델만 별도 모듈로 분리한다. 운영 engine.py·주문·UI는 수정하지 않는다.
3. 필요한 경계만 검사한다: g−l=n, 단위 변환, 동일 학습 경계/미래 입력 불변,
   상수0 head, 전처리 격리, 비용 이중 차감 없음, h5/지연 일정, 슬롯 대조의 사후 정보 차단,
   선정 후 결손/null, 부분 완결과 전체 판정 구분, 만기 잔량의 재시도 종료일 보존,
   가격 꼬리 뒤 확정 현금만의 T+2 해소, 현금·수량 보존.
4. 독립 코드 검수와 구현 사전커밋 뒤 고정 실행을 한 번 수행한다. 성과를 본 뒤 바꾼
   전략으로 같은 실행 ID를 덮어쓰지 않는다. 출력·학습 모델·원천/계획/코드 해시를 보존한다.
5. 판정·한계·최초 조건 위반을 문서화한다. 정확한 PR HEAD의 CI 통과 후 연구 변경만
   머지한다. 기각 시 다음 후보를 자동 생산하지 않는다.

예산은 최대20fit·160코호트 경로·100계좌 경로다. 작은 로컬 CPU 모델이며 GPU·LLM
추론·유료 데이터·새 서버는 없다. 로컬 시간·메모리는 실제 측정해 보고하며 미리0원 운영
비용이나 완료 시간을 보장하지 않는다. 기존 테스트 전체를 불필요하게 복제하지 않는다.
