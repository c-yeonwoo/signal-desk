## 소비 범위와 재개 판단

- 특성 적격성과 기존 단위 검사는253종가의 내부252쌍을 조사한다. 당일 가격 적격 집합·재무 roster·원래 제외 규약을 그대로 사용하고, 실제 예측행 목록은 별도로 보존한다. 22,922종목일을 예측행 수라고 부르지 않는다.

- 정확한 `(ticker, 이전 세션, 변화 세션)`을 합치고 값·원천ID·검수 근거·소비 층·판단일·관련 보존 경로를 연결한다. 오래된 원장의 다른 날짜 사건을 같은 회사 전체의 승인으로 확장하지 않는다.

## 실행 방법

저장소 루트에서 Python3.12로 실행한다. 출력은 독점 생성되어 기존 결과를 덮어쓰지 않는다. 아래 출력 경로가 이미 있으면 새 경로를 지정하되, 증거가 바뀌지 않은 전체 집계를 반복할 필요는 없다.

```bash
.venv/bin/python -m scripts.measure.kr_ridge_source_inventory \
  --repo /Users/ys.choi/dev-private/signal-desk \
  --output data/research/kr-r3-batch-source-inventory-2026-10-18-v1.json \
  --source-supplement docs/kr-r3-hyundai-source-supplement-2026-10-18-v2.json \
  --source-supplement-archive data/research/kr-r3-hyundai-source-supplement-2026-10-18-v3.zip \
  --supplement-commit ae6396eb34edc9c64547a9ad1a00e2b119c3279a \
  --event-supplement docs/kr-r3-celltrion-kia-source-supplement-2026-10-18.json \
  --event-supplement-commit ae6396eb34edc9c64547a9ad1a00e2b119c3279a
```

`inventory_complete`와 exit0은 목록 생성 완료이며 백테스트 합격이 아니다. 부분 CLI 인자, 해시/검수 충돌, 입력 변경은 exit2다. import 시 수집/자료 읽기를 하지 않고, CLI 실행에서 네트워크·학습·예측·라벨·전략 재생을 차단한다. CPU/wall 상한은600초다. 기준 커밋의 조상 관계와 원입력 해시를 검증하므로 도구 자체를 머지한 뒤에도 사용할 수 있다.
