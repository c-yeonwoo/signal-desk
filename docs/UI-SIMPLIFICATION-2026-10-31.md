# Signal Desk 화면 단순화

소유자가 선택한 첫 과업은 **지금 새로 살 만한 후보 확인**이다. 일상 화면은 오늘·내 투자 두 메뉴로 정리하고 오늘에서 후보와 전체 종목 탐색을 연결한다. 구현 전 기준은 main `3ca5ec34bedcfaaf4062aead85169c16cb776481`이다.

## 적용 범위

| 단계 | 사용자 변화 | 상태 |
| --- | --- | --- |
| 1 | 오늘의 후보·종목 상세·기본 메뉴 정리 | 구현·로컬·독립 검수 완료, CI·머지 상태는 PR 기록 참조 |
| 2 | 내 보유 조회와 분석 입력의 작업 흐름, 모의투자 성과 우선 배치 | 후속 |
| 3 | 관리자 내부·공통 문구·나머지 화면의 정보 밀도 정리 | 후속 |

디자인 단계 완료는 투자 수익성의 진행률이 아니다. 이전 통합40%를 이 작업의 성과 점수로 사용하지 않는다.

## 첫 화면

국내·해외·관심종목을 유지한다. 매수 운영/가격 상태 → 최종 후보 최대3개 → 전체 후보와 종목 찾기 → 시장 한 줄과 접힌 근거 순서다. 상위3개는 표시량이다. 기존 최종 등급·점수 순 정렬을 재사용하고 조건을 완화하거나 공석을 채우지 않는다.

후보의 좋은 이유와 주의점은 기존 `score_contributions`와 구조화된 차단 사유로 설명한다. 뉴스 감성을 점수 이유로 섞거나 LLM 설명을 새로 생성하지 않는다. 수신 시각은 한국시간으로 표시하며 원천 시각 인증이라고 부르지 않는다.

정상적인 후보 없음, 분석 자료 미수집, 가격 무효, 장외 종가 참고, 봇 매수 보류, 운영 상태 미확인, 조회 실패를 구분한다. 오래 열린 화면은30초마다 가격 만료를 다시 확인하며, 실패한 갱신 뒤의 캐시는 지난 기록으로 표시한다. 이 로컬 만료 검사는 전체 세션 공급 연속성이나 투자 정확도의 인증이 아니다.

## 종목 상세

신규 후보와 보유 대응을 구분한다. 기본 라벨은 매수 후보/종가 참고 후보이며 원래 계산 등급은 ‘등급과 점수’에서 확인한다. 가격·시그널 점수·B/S·툴팁·3개 차트 모드는 보존한다. 후보 기록 뒤 하락은 접힘을 기본으로 숨기지 않는다. 긍정적인 과거 변화와 상세 지표는 필요할 때 펼친다.

시그널 검증은 더 보기의 판정 검증으로 옮기고 기존 내 투자 연결도 같은 진입 함수를 사용한다. 기존 signal/watchlist/cycle/admin 딥링크와 관리자 권한 검사는 유지한다.

## 검수

실제 운영의 이전 화면은 읽기 전용으로 관찰했다. 새 화면은 실제 HTML/JS/CSS에 외부 API·계좌·환경파일을 사용하지 않는 로컬 합성 응답을 연결해 검수했다. 캡처의 가격과 판단은 예시다.

- PC1440×1000, 모바일390×844에서 첫 화면·목록/상세 이동·관심 표시·가격/점수 차트와 B/S·가로 넘침을 확인한다.
- 별도 정상/장외/매수 보류/가격 지연/후보 없음/조회 실패 입력으로 상태를 대조한다.
- 기존 UI 검사와 추가 실제 JS 검사로 최종 순서·빈자리 보존·미확인 상태·비동기 시장 전환·만료·포커스·과거 기록 표시를 확인한다.
- 독립 리뷰에서 관심 초기화 건너뜀, 숨겨진 검증 패널 연결, 주기적 포커스 소실을 발견해 수정했다. 후속 검수의 분석 불가/후보0 혼동도 수정했다.
- Impeccable 검사1회를 실행했다. 새 CSS의 글자 크기는 공통 토큰으로 정리했다. 기존 단일 HTML의 경고와 오래된 디자인 sidecar는 이번 변경의 접근성 인증이나 전체 오류0으로 포장하지 않는다.
- 독립 화면 마감 리뷰의 최초 조회 실패 문구1건을 수정한 뒤 해당 캡처를 다시 확인해 ship 판정을 받았다. 최초 실패는 과거 기록이나 정상적인 후보0으로 표현하지 않는다.
- 관련 검사271개 통과 후 추가된 후보 화면 경계 검사8개도 통과했다. 처음 전체 검사에서 새 UI와 달라진 기존 문구/위치 검사4개를 수정했다. 후속 전체 검사의 포커스 기대값1건은 실행 도중 바뀐 재조회 버튼 동작과 달랐으며, 최종 경계 검사에서 재조회 버튼으로 포커스를 복구함을 확인했다. 최종 PR CI는 별도 확인한다.

정확한 CI·PR·머지 및 운영 확인은 최종 전달 때 기록한다. UI 합성 검수만으로 운영 가격·수익·실주문 실행을 확인했다고 말하지 않는다.
