# SIG-28 · 시장에서 종목으로

기준 main `e3e5c8ca34dc5fd0fe3bb4420812b568cd04b880`. 실제 로그인된 운영 ‘오늘’ 화면에서 등락 종목은 공유 이미지 안에만 있고, 종목 상세로 이동할 수 없었다. 당일 상승과 최근 추세를 함께 설명하는 기존 API의 문장은 근거보다 덜 드러났다. 이미 제거한 장식 그림이나 상대강도 목록을 다시 제거한 작업으로 세지 않는다.

## 이번 변경

- 시장·종가 기준일 → 당일과 최근 추세를 함께 설명하는 기존 요약 → 확인한 종목 수 → 매수 판정 현황 → 종목 목록의 순서다. 전체 관찰 대상, 기준일 종가 확인 수, 직전 거래일과 비교 가능한 수를 구별한다. 시장 전체 지수 수익률로 표현하지 않는다.
- 기존 API가 반환하는 등락 폭 상위 최대3종목을 HTML 버튼으로 보여준다. 클릭하면 기존 종목 상세로 이동한다. 이 목록은 매수 추천 순서가 아니며 시그널 순위·판정을 바꾸지 않는다.
- 기존 검증된 원문 링크에 기준일을 붙인다. 당일 기사 미연결은 호재·악재 없음과 구별하고, 같은 날 기사라는 이유로 등락 원인으로 단정하지 않는다.
- 기존 공유 이미지와 경제 지표는 각각 접어서 유지한다. 이미지 생성이나 LLM 호출을 추가하지 않았다. 최신 종가가 없거나 요청이 실패하면 이전 종목과 원문을 숨기고 재시도를 제공한다.
- 모바일 시각 순서와 DOM/키보드 순서를 맞춘다. 종목 차트·가격/시그널 선·B/S·모드·툴팁, 계좌·주문·API·엔진·연구는 변경하지 않았다.

## 검수

실제 정적 앱에 합성 API만 연결한 격리 화면에서 PC·390px 모바일·긴 종목명·국내200/해외509·일부198/200·지연·HTTP실패·재시도를 확인했다. 합성 시세는 운영 데이터 인증이 아니다. 원문은 공개 링크의 href와 표시 기준일을 확인했으며 새 기업 원문 수집을 수행하지 않았다. 같은 국내 요청의 재시도와 국내→해외 응답 경합은 실제 함수 실행 테스트로 확인한다.

[PC](../.impeccable/review/pd4/desktop.png), [모바일](../.impeccable/review/pd4/mobile.png), [오류](../.impeccable/review/pd4/mobile-error.png), [출처](../.impeccable/review/pd4/captures.json). 실제 운영의 계정/보유 정보가 포함될 수 있는 캡처는 회사 runtime에만 남긴다.

Impeccable Operate 원칙으로 장식보다 읽는 순서·짧은 설명·다음 행동을 우선했다. 전체 HTML의 기존 온보딩/dialog/클리핑 등 기계 검사 경고는 남아 있으며 전체 접근성 인증이나 로딩 속도/투자 수익 개선을 주장하지 않는다. 기존 전역 DESIGN.md의 drift는 PD5 범위이며 이번에 부수적으로 재작성하지 않는다. 독립 코드·마감 리뷰, 정확한 HEAD CI, 머지, 운영 자산 해시와 실제 UI 검수는 전달 기록에서 구분한다. 소유자의 실제 수용은 추정하지 않는다.

완료 집계는 위 전달 증거를 모두 확보한 뒤 PD4를4/6으로 반영한다. 디자인 완료는 수익성 검증이 아니므로 통합 로드맵은40%를 유지한다.
