기존 인디고를 중심으로, 밝은 중립 표면과 선명한 글자를 사용합니다. 행동은 인디고, 수치의 변화는 녹색·적색, 확인이 필요한 조건은 황토색으로 구분합니다.

설계용 정적 시안 · 아래 종목·수치·시각은 합성 예시입니다. 운영 데이터나 주문 기능이 아닙니다.

03 / 팔레트 · 11가지 역할

인디고와 청회색의 가까운 색상 관계를 바탕으로, 녹색·적색·황토색을 필요한 상태에만 제한합니다. 배경과 표면이 대부분을 차지하고 강조색은 작은 영역에 씁니다.

04 / 글자 조합과 대비

아래 AA 표시는 해당 색 조합의 일반 텍스트 대비 4.5:1에 대한 판정입니다. 페이지 전체의 접근성 인증을 뜻하지 않습니다. 대비는 반올림 전 값으로 판정합니다.

05 / 반복해서 적용할 규칙

글자를 먼저

본문 16px, 설명 14px, 시각 13px. 위험과 제약을 흐린 작은 글자에 숨기지 않습니다.

카드 안에 카드를 쌓지 않습니다. 근거는 간격과 구분선으로 묶고 중요한 상태는 가까이 둡니다.
