# R3 현대차 보완자료 연결 후 실제 실행 결과

**판정: 연결 도구는 검수 통과. 후보 전략은 자료 제약으로 미채택. 수익성 기각이나 0% 수익이 아니다.** 현대차 소각 원문을 연결한 뒤 실제 재생을 1회 실행했으나 다음 두 미검수 주식수 변동에서 거래 전에 중단됐다. 수익 개선은 입증하지 못했고 운영 시그널·주문·연구 채택 조건은 변경하지 않았다.

- 원계약·원래 35개 입력·원본 8사건을 유지하고 [별도 보완 명세](KR-R3-HYUNDAI-SOURCE-SUPPLEMENT-2026-10-18.md)와 [기계 명세](kr-r3-hyundai-source-supplement-2026-10-18.json), 실제 코드를 사전 커밋 `494009a6339012b38ae011844a984739b68df701`에 고정했다. QA의 사전커밋 대사와 최종 보고 확인 뒤 controller가 실행했다.
- 검수 사실은 8→9건이다. 현대차 `005380 / 2024-04-16`의 미검수 중단 사유는 해소됐다. 수량·가격 배율 변경, 종목 제외, 특성·가중치·선정·기간·비용·매매 규칙 변경은 없다.

## 실제 1회 재생

새 출력은 `data/research/kr-ridge-hold-renewal-diagnostic-2026-10-18-supplement-v1.json`이며 SHA256은 `a39ec92e48b55cbc35c2d46644308955ddd8c9b63a595450b8c0956613b6143d`, 크기는 2,495,488바이트다. 실측은 wall **9.486914초**, CPU **8.999044초**다. 추가 수집0회·학습0회·재생1회이며 기존 출력은 덮어쓰지 않았다. 원래 실패 결과 SHA256 `ad7bd5f5a4719e212ca4bc0dc39527d0870a655aaa3cb74829fbdc2ff5d201c4`도 그대로다.

| 구간 / 위상 | 다음 미검수 입력 이력 | 그룹 수 × 3팔 | 체결 / 완결 |
| --- | --- | ---: | ---: |
| 2024Q4, 0~4위상, 두 비용 | 셀트리온 `068270`, 2024-01-12 | 10 × 3 = 30계좌 | 0 / 0 |
| 2025Q1, 0·1·2·4위상, 두 비용 | 기아 `000270`, 2024-05-28 | 8 × 3 = 24계좌 | 0 / 0 |

총 **60거래계좌 모두 미완결**, 제출·체결·완결 매수 lot은 모두0이다. 초기 현금 1,000만원은 최종 전략 수익이 아니다. 최종 손익·수수료·MDD·팔 간 손익 차이는 null이다. 일부 거래 전 현금 prefix의 낙폭0을 최종 MDD0이나 전략 합격으로 읽지 않는다. 현금2선은 대조선이지 거래 표본이 아니다.

`state=price_diagnostic_finished`, exit0은 진단 절차 종료이며 역사 성과 검증 완료가 아니다. `observedGateFailures=[]`, `minimumNotMet=[]`도 합격이 아니다. 평가 구간 30계좌가 `sourceOrTimeoutIncomplete`에 남고 `limitedDevelopmentPriceSupport/adoptionClaim/historicalResearchAdoption/livePromotion`은 모두 false다. 구현 실패 목록은 비어 있다.

## 새로 드러난 결손과 재개 조건

보존 KRX 원문에서 다음 전후값을 직접 읽었다. 가격·주식수 변동만으로 사건 종류나 외부 보유자 효과를 추정하지 않는다.

| 종목 | 전일 → 변동일 | 상장주식수 전 → 후 |
| --- | --- | ---: |
| 셀트리온 068270 | 2024-01-11 → 2024-01-12 | 146,402,770 → 220,290,520 |
| 기아 000270 | 2024-05-27 → 2024-05-28 | 402,044,203 → 399,858,417 |

이들은 당시 매수 후보뿐 아니라 시장 대표값·순위 특성에 소비되는 과거 가격 이력이다. 현재 선택되지 않았다는 이유로 지우지 않는다. 사건일과 실제 중단일(판단 종가)을 구분한다. 실제 그룹별 중단일·마지막 공통 마감·전 원장은 새 출력에 보존했다.

다음 과제는 **두 정확한 키의 기존 보존 원문·검수 사실 연결 가능 여부를 먼저 확인**하고, 부족하면 해당 사건 원문으로 가격 단위·보유자/권리 영향을 분리하는 것이다. 이번 명세는 현대차 한 사건만 허용하므로 다른 변동을 무조건 `unchanged`로 바꿔 재실행하지 않았다. 새 근거와 별도 연결 명세 없이 동일 자료를 반복 재생하지 않는다. 새 원문 확보가 나머지 모든 결손까지 해소한다는 보장도 없다. 추가 거래일 관측을 기다리는 문제가 아니다.

원문 수집은 앞선 SIG-17의 15회로 종료했고 누적 행사 요청은281/400, 가격/메타데이터810/1,200을 유지한다. 이번 결과를 더 좋게 만들기 위한 추가 수집·공식 원장 변경·유료 문의·차기 후보 실행은0이다. 총수익/PIT 인증·기존210경로의 자료 차단도 유지한다.
