# 운영 선정과 과거 연구 선정 대조

## 결론

과거 연구의 `legacy`는 실제 운영 명단이 아니다. 엔진 코드는 같지만 입력과 설정 연결,
가격 평가 시각, 후처리·주문 정책이 달랐다. 이번에는 운영 관리자에 접속해 실제 보존
판단의 재생 일치, 설정, 기록 사례와 모의 체결까지 대조했다.

**운영 저장 판정 뒤 하락한 사례는 확인했으나 수익성 개선을 입증한 규칙 변경은 없다.**
새 매매 규칙을 채택하지 않는다. 연구 입력 차이를 측정하는 읽기 전용 감사만 추가했다.

처음 의심했던 후단 필터가 이 기간의 후보 축소를 일으켰다는 설명은 기각한다.

## 실제 오선정을 설명하는 범위

사용자가 이미 제시한 HD현대(267250)의10/8 기록은점수+2.28·2위·강력매수·커버리지0.88이며,
신규 매수 게이트가 열려 있었다. 다음 정규장10/12 시가179,600원을 기준으로
10/16 종가158,600원,5일 가격 수익−11.6927%였다. API의 가정 왕복0.25%를 빼면−11.9427%다.
이는 실제 사용자 체결 손익이나 bid/ask 체결 재현이 아니다.

같은 사례의 기록 경로는10/12에 신규 매수 차단을 남겼고,10/15 손실 관측 전 일반 매도는 없었다.
차단은10/8 판단 뒤이므로10/12 시가 진입을 미리 막았다고 볼 수 없다.
10/22에도점수+2.29·2위였지만 추세 게이트가 닫혀 최종 라벨은HOLD였다.
**높은 상대 점수가 남는 문제, 신규 진입 차단, 보유 청산은 서로 다른 판단**임이 실제 기록에서 확인된다.
단순히“점수가 높으니 계속 보유”로 해석하면 운영 위험 관리와 어긋난다.

해당10/8 사건의 세 기준 모의봇 원장에는 이전 순수량0,이후 조회창 내 체결0이었다.
창 끝11/6은 아직 미도래했다. 이 사실로 사용자 계좌 체결이나 텔레그램 발송 여부를 추정하지 않는다.
현대차(005380)의9/1 저장 판정은+0.99·44위·HOLD·추세 차단이었다.
사용자가 본 차트의9/1 가격/점수는 그날 새 강력매수가 발생했다는 증거가 아니다.
최초 매수 추천일이 다른 경우 그날 기록과 계좌 진입가를 따로 연결해야 한다.

## 채택 판단과 후속 범위

1. 가격 전용168건과 R3의13건을 같은 운영 선정력으로 취급하지 않는다.
2. HD현대 사례는 진입 판단 실패와 일반 매도 부재를 설명하지만,어떤 새 청산 규칙이
   비용 후 손익을 개선하는지 입증하지 않는다. 이미 기각한 일률5일 청산도 재채택하지 않는다.
3. 10/23처럼 원시 입력이 보존된 판단은 정확한 설정·가격·팩터·게이트로 대조할 수 있다.
   수익 개선 실험은 이 계약과 기존 개발 자료의 입력 계약이 맞는 범위에서만 시작한다.
   원시 입력이 없는 보호 구간을 추정 보충하거나 그 손실에 맞춰 규칙을 학습하지 않는다.

신규 도구는 연구 원장 입력 차이를 재현하고 운영 기록의 메타데이터 재고만 확인한다.
운영 엔진·주문·가중치·문턱 변경0,수익성 개선 미입증,**통합40/100 유지**다.
