# 장중 기회 전략 검증 — 구현 범위와 남은 증거

2026-10-10 기준. 이 코드는 기존 등록 8팩터 엔진과 봇·실주문을 바꾸지 않는 **연구 경로**다. 목표 수익률이나 전략의 우위를 검증했다고 표현하지 않는다.

## 이번 수정으로 실제 달라지는 것

- 첫 KIS 현재가·거래량 관측만 있어도 **완료된 연속 10개 분봉**의 앞/뒤 5분 거래량이 모두 양수이고 최근/이전 비율이 1.5 이상이면, 가격 급변 후보를 `watch`에서 연구용 `shadow`로 옮길 수 있다. 누적 거래량의 유효한 구간 증가도 기존처럼 인정한다. 원천 시각이 맞지 않거나 10분봉 중 하나라도 빠지면 보류한다. 어느 경우에도 `order_eligible=false`다.
- 관리자 연구 화면의 최근 200건은 **보여주기 전용**이다. 검증은 시장·날짜·전략별 이벤트 ID 정렬 첫 3건을 별도로 뽑는다. 표본이 4,000건 상한에 걸리면 판정을 중단한다. 날짜 수와 표본 건수를 화면에 표시한다.
- 각 날짜의 전략 선택에는 그날보다 이른 완료 관측만 사용한다. 선택된 전략의 이후 날짜 가상 손익을 같은 날짜·장세의 관찰 후보 평균과 비교한다. 최소 30개 학습 날짜와 10개 전진 평가 날짜가 없으면 결과를 숨긴다. 하루의 여러 이벤트는 독립 날짜 하나로 평균한다.
- 탐지 루프마다 가격 행이 있는 종목, 신선한 종목, 5분 비교가 된 종목, 급변 후보, KIS 현재가·완료 분봉 요청/성공, 실제 거래량 근거 수를 별도 원장에 기록한다. 후보가 0건이어도 `시세 행 없음`·`비교 가격 부족`·`급변 조건 없음`을 구분한다. 관리자 화면의 최근 기록과 갱신 경과는 **앞으로의 실제 운영 관측**을 확인하는 도구이지 배포 전 성공 증거가 아니다.
- 기본 관찰 종목 밖을 발견하기 위한 **국내 순위 레이더의 읽기 전용 경로**를 추가한다. `INTRADAY_RANK_RADAR=1`에서만 [KIS 등락률 순위](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_stock/fluctuation/fluctuation.py)와 [거래량 순위](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_stock/volume_rank/volume_rank.py) 첫 페이지를 최대 15분에 한 번 조회한다. 각 목록에서 최대 10개씩 유효한 보통주 코드를 다음 토스 시세 배치에 20분 동안 추가해 **그다음의 실제 5분 가격 변동**만 관찰한다. 순위의 당일 등락률을 5분 수익률로 오인하지 않는다. 공급자 응답 모양·쿼터·정규장 성공률이 미검증이어서 기본값은 꺼짐이다. 플래그를 켜면 추가 종목의 가격은 공용 장중 가격 원장에도 기록되지만, 기본 매수 우주·주문·사용자 추천은 바뀌지 않는다.
- 과거 분봉 확보 가능성은 [KIS 주식일별분봉조회 공식 예제](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_stock/inquire_time_dailychartprice/inquire_time_dailychartprice.py)로 확인했다. 최대 1년 보관·호출당 최대 120행이며 실제 계정의 반환 범위는 미검증이다. 관리자 `/api/admin/research/intraday-minute-probe?ticker=005930&session=2026-07-14`는 **사전등록 보호 시작 전인 2026-08-04 이전 개발 날짜** 한 종목·한 페이지만 읽고, 가짜 봉을 채우거나 기존 원장에 역기입하지 않는다. 반환된 분봉 날짜가 각 행에 명시되지 않으면 `date_attested_by_rows=false`로 남긴다. 이 진단은 과거 전략 손익 계산도, 전체 8팩터 재생도 아니다.

## 판정할 수 없는 것

1. 기본값에서는 현재 시세 원장의 국내 기본 종목군·미국 기본 종목군 및 제한된 관심/보유 종목 밖을 탐지하지 못한다. 국내 순위 레이더를 켜도 상위 두 목록의 일부만 추가한다. 이것은 시장 전수 급등 레이더가 아니다.
2. 미국은 장중 거래량 근거가 없고, 국내 KIS 분봉·현재가는 서버 수신 시각이다. 외인·기관은 가집계다. 호가·체결 가능 수량·시장 충격의 검증된 기록도 없다.
3. 가상 재생은 다음 실제 가격 관측을 사용하지만, 고정 왕복비용 25bp와 양쪽 10bp 슬리피지 가정이다. 호가 기반 실체결이나 지연 주문의 수익으로 해석할 수 없다.
4. 날짜별 고정 표본과 전진 평가는 이번 변경에 정의된 **탐색적 연구**다. 이미 본 과거 결과로 전략을 고른 뒤 같은 기간을 독립 OOS라고 주장하지 않는다. 사전등록 보호 구간의 기존 헤드라인·가중치·문턱에는 손대지 않는다.
5. 실제 장중 수집 안정성, 미장 거래량 소스, 시장 전수 탐지, 호가 기반 비용, 전략의 독립 실전 성과는 아직 확인되지 않았다. 주말인 10월 10일에는 새 정규장 관측을 만들 수 없다.
6. 로컬에는 KIS 실계좌 조회 자격이 없어 과거 분봉 API의 실제 응답을 확인하지 못했다. 운영 관리자 진단도 호출 전까지 결과를 알 수 없다. 출처 날짜가 불명확하거나 페이지가 빠지면 백테스트 표본으로 승격하지 않는다.

## 다음 수집·승격 관문

국내·미국 정규장에서 (a) 관측 대상·갱신 지연·KIS 성공/실패·완료 분봉 비율, (b) 이벤트별 출처·가용 시각, (c) 다음 가격과 당시 호가, (d) 날짜별 전진 결과와 비거래 대조군을 차례로 확인한다. 결측이나 비용 불명은 기권한다. 자동 주문 연결은 별도 제안과 사용자 승인, 독립 기간의 비용 후 우위, 주문·손실 안전장치 검증 전까지 금지한다.
