# 매출 확인·가이던스 하향 회피 · 가격 전 고정 계획

2026-10-17. 기존 2022/2023 실적 실험의 손실·NVDA 집중을 본 뒤 만든 **새 가설**이다. 기존 실험을 수정하거나 이미 본 2023년을 독립 검증으로 재사용하지 않는다. 이 문서를 커밋한 뒤 새 표본의 기사·호가를 수집한다. 코드 완성이나 양의 연구 수익만으로 주문을 열지 않는다.

## 표본과 원천

- 동일한 고정 생존 회사 8개: AAPL·MSFT·GOOGL·AMZN·META(당시 FB)·NVDA·JPM·XOM.
- **2020년 개발 32발표, 2021년 독립 확인 32발표**. 기존 Alpha Vantage 원문 묶음에서는 발표일·회계기간만 읽었다. 각 회사·연도 4발표가 아니면 중단한다. 이미 가격을 검사한 2022~2025년과 분리한다. 2020년 결과를 보고 2021년 규칙을 튜닝하지 않는다.
- Alpaca/Benzinga 당시 기사 제목의 실제 EPS·매출·예상치·다음 분기 총매출 전망을 쓴다. 현재 벤더 예상치를 소급하지 않는다. 원문 버전·실제 API 도착 시각 미인증인 **조건부 역사 재구성**이다. 실제 회사 발표와 뉴스 숫자의 충돌은 별도 감사 대상이며 가짜 확정값으로 고치지 않는다.
- 기사·SIP 원문 SHA/수집 시각/수정 시각/실패·페이지 누락을 보존한다. 보호 구간·SEC 무연락처 수집·5년 일봉 백필·보간은 없다. GET 범위만 2020년부터 허용하며 키·주문 권한·운영 시그널은 그대로다.

## 변경 가설 하나

**EPS만 예상보다 높다고 사지 말고, 총매출도 예상보다 높으며 이미 공개된 다음 분기 매출 전망이 예상을 밑돌지 않는 사건만 산다.**

1. 직접 단일 회사의 실적 EPS 비교 제목을 사용한다. 조정/미명시 기준을 구분하고 양의 실제·예상 EPS에서 상회율 5% 이상을 요구한다. 최초 이용 가능 비교를 택하며 나중 정정으로 앞선 판단을 소급 취소하지 않는다. 동시 충돌은 미확정으로 남긴다.
2. 최초 직접 실적 기사 공개/수정 중 늦은 시각 **+10분**에 한 번 판단한다. 그 시각 전에 이용 가능한 같은 회계분기의 총매출 실제·예상 비교가 있어야 하며 실제가 예상을 엄격히 넘어야 한다. 부문 매출·연간 매출·EPS를 총매출로 읽지 않는다.
3. 같은 시각 전 공개된 **다음 회계분기 총매출** 전망과 같은 기간 예상치가 모두 있으면 범위 중간값을 비교한다. 전망 중간값이 예상 이하이면 관망한다. 전년 실적·매출 성장률·부문 전망을 다음 분기 총매출 예상으로 대체하지 않는다. 전망 비교가 없으면 `unknown`으로 표시하고 매출 조건까지만 적용한다. **가이던스 미확인을 호재로 해석하지 않는, 명시적 하향 전망 회피 정책**이다.
4. 미래 기사·늦은 수정·실적 콜의 나중 발언을 10분 전 판단에 끼워 넣지 않는다. 기간/단위/동시 비교가 모호하면 해당 숫자는 쓰지 않는다. 알려진 정책상 관망과 수집 실패를 구분한다.

## 체결·대조·비용

- 진입은 위 판단 후 첫 유효 SIP 기준 ask, 적어도 1초 뒤 실제 ask에 기준 ask×1.003 지정가 상한. 현금 $10,000, 건당 현금 1/6 이내, 정수 주식, 레버리지 없음, 뉴욕 날짜당 가장 먼저 판단 가능한 사건 하나(동시에는 티커순). 보유는 실제 진입+60분 뒤 첫 수량 충족 bid까지다. 장전/장후·달력·희소/부분 응답·미확정 포지션 처리는 기존 실험과 같다.
- 과거 round lot×100 해석을 기본으로 하고 원시 수량을 주 수로 취하는 보수적 상한도 별도 보고한다. 단위·호가가 실제 체결을 인증하지 않는다는 제한을 유지한다.
- 대조: **같은 10분 시점의 EPS-only**, 새 정책과 같은 결정 시각 SPY, 현금. 서로 다른 시점·수량의 이익 차이를 순수 필터 효과라고 부르지 않는다. 기본 편도10bp 가정, 편도25/50bp·추가60초·절반 수량·전량 미체결을 보고한다. 실제 역사 계좌 비용 후 수익은 null이다.
- 대량 원문과 거래별 가격은 로컬 전용, 공개 저장소에는 해시·집계·간단한 사실·출처만 싣는다.

## 가격 전 채택 기준

2021년 확인에서 원문·선택·체결·모든 대조/스트레스가 완전해야 한다. 기본 새 정책 **12거래 이상·6회사 이상·각 분기 2거래 이상**, 네 분기 순이익 모두 양수, 기본 수익이 양수이면서 모든 대조를 초과, 편도25bp·추가60초·절반 수량에서도 양수여야 한다. 추가로 **한 회사의 양의 손익이 양의 회사 손익 합계의 50%를 넘지 않고**, 각 회사를 제외해 현금 경로·날짜당 선택부터 재계산한 결과가 모두 0 이상이어야 한다. 부족한 거래나 가이던스 범위를 나중에 완화하지 않는다. 50bp는 별도 극단 스트레스이며 합격 필수 조건은 아니다.

실패하면 `not_adopted`로 종료한다. 통과해도 `passed_conditional_reconstruction_only`이며 실제 API 도착·계좌 비용·모의 체결·독립 운영·사용자 주문 승인은 별도다. 기존 등록 헤드라인·가중치·매매 규칙과 통합 진행률 40/100은 변경하지 않는다. 소스 접근이 실패하면 실패 원문과 범위를 남기고, 다른 연도를 성과를 본 뒤 골라 대체하지 않는다.
