# R3 현대차 자기주식 소각 보완자료 실행 명세

이번 변경은 [원래 후보 계약](KR-R3-HOLD-RENEWAL-CONTRACT-2026-10-18.md)의 매매 정책을 고치는 실험이 아니다. 최초 실행을 막은 현대차 한 사건에 새 원문 검수 사실을 연결한다. 후보 결과를 재계산하기 전에 이 명세·보완 입력·실행 코드를 커밋한다. 원계약 바이트와 기존 실패 결과는 보존하며 새 자료를 썼다는 사실과 해시를 별도 결과에 남긴다.

## 근거와 허용 범위

- [SIG-17 원천 검수](http://127.0.0.1:3100/SIG/issues/SIG-17)의 실제 보고 개정은 `8fa30c63-da5f-4dea-87f3-6ed0e425fbdd`, 보고 SHA256은 `02bd5a0fdd80196cbcfce253d9dc97b8c76b95c499b7602d8b06507285898b14`다. 보고 작성자·실행·서버 activity와 보존 파일 해시를 대조했다.
- [회사 소각 결정](https://kind.krx.co.kr/external/2024/03/21/001460/20240314006517/61131.htm)은 기취득 자기주식 소각이며 자본금 감소가 없다고 명시한다. [거래소 변경상장](https://kind.krx.co.kr/external/2024/04/11/000067/20240411000179/68155.htm)의 보통주 감소량이 KRX 보존 행과 일치한다.
- 유일한 보완 키는 `2024-04-16 / 005380 / KR7005380001 / ordinary_common`이다. 전일은 `2024-04-15`, 상장주식수는 `211531506 → 209416191`, 소각수는 `2115315`다. 소각 효력일 `2024-03-27`과 변경상장일 `2024-04-16`을 구분한다.
- 회사 결정의 표시 공개시각은 `2024-03-21T16:27:00+09:00`, 변경상장 통지는 `2024-04-11T16:46:00+09:00`이다. 원문 조회는 2026년이다. 당시 수집본/PIT 보존 또는 전 정정·취소 이력의 완전성으로 인증하지 않는다.
- 해당 자기주식 소각에 한정한 외부 주주의 보유수량 배율과 가격 표시 단위는 1로 검수했다. 가격·보유수량을 0.99배 또는 그 역수로 조정하지 않는다. 소각 장부금액을 주주 지급액으로 계산하지 않는다. 다른 배당·권리의 존재나 정산은 이 자료로 인증하지 않는다.

## 구현·검수와 1회 실행 조건

1. 보완 자료의 해시, 두 원문의 회사/증권/수량/날짜/자기주식 소각 근거, 실제 KRX 전일·전후 수량이 맞아야 한다. 다른 증권·날짜·수량, 변조·중복·상충, 불명확한 자료는 기권한다. 임의 JSON의 `unchanged` 주장만으로 관문을 통과시키지 않는다.
2. 특성 이력, 당일 단위 검사, MA20이 같은 검수 사실을 참조한다. 소각일을 변경상장일로 대체하지 않고 하루말 관측을 당일 개장 입력으로 소급하지 않는다. 기존 예측·선정·매매 정책·현금/결제 처리는 바꾸지 않는다.
3. 구현과 다른 담당의 코드/원문 검수 뒤 controller가 명세·코드·입력을 사전 커밋한다. 별도 새 출력 파일에 **추가 수집 0회·학습 0회·실제 백테스트 1회·최대 600초**로 실행한다. 원천 수집은 SIG-17의 15회로 종료했으며 누적 행사 요청 `266 + 15 = 281/400`을 유지한다.
4. 비교는 원계약 그대로 2024Q4 개발·2025Q1 과거 평가, 75/120bp, 5위상, 강제 왕복/순수량/후보의 60계좌와 현금 2선이다. 기존에 본 평가 자료이며 pristine OOS가 아니다. 더 나은 구간이나 비용을 다시 고르지 않는다.
5. 다음 다른 원천 결손을 만나면 날짜·종목·단계·실제 체결·마지막 공통 마감을 보존하고 해당 결과를 미완결/null로 끝낸다. 같은 입력 재실행, 다른 종목 제거, 문턱 완화, 자동 추가 수집은 하지 않는다. 구현 결함을 확인한 경우에만 별도 수정·검수 근거를 기록한다.

## 채택 판단

원문 연결의 정확성, 코드/CI 통과, 비용 후 가격정책의 성과, 역사 총수익 인증, 실전 승격을 따로 판정한다. 성과는 원계약의 모든 위상·최소 표본·낙폭·집중도·두 대조군 기준을 그대로 적용한다. 미완결 경로가 있으면 빈 실패목록이나 일부 유리한 prefix를 합격으로 읽지 않는다. 완결되고 문턱을 못 넘으면 해당 후보를 기각하며, 자료 때문에 비교할 수 없으면 자료 제약으로 미채택이다.

코드가 정확하고 CI가 통과하면 진단 도구는 머지할 수 있다. 그것이 운영 전략 변경이나 수익성 채택을 의미하지 않는다. 실제 수익 개선 근거 없이 통합 진행률 40점을 올리지 않는다. 신규 거래일을 기다리는 과제가 아니며, 다음 단계는 이번 새 근거를 연결한 실제 한 번의 비교다.
