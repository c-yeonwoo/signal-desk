# SIA 공개 월간 반도체 매출 카드

기준: 2026-10-08 · 적용: 읽기 전용 관측, 국내 마감 뒤 최대 3일 간격 · 상태: 코드/테스트 완료, 운영 검증 대기

## 사용 범위와 제한

- 수집 대상은 SIA가 공개 웹사이트에 올린 월간 보도자료의 제목·게시시각·링크와 본문에 명시된 세계 매출액, 전월/전년 비교율, 비교 기준 금액이다.
- WSTS/SIA 구독 대시보드, 회원사 자료, 유료 원자료·세부 분류는 요청하거나 저장하지 않는다. 기사 전문도 저장하지 않는다. 응답은 메모리에서 파싱하고 본문 SHA-256만 짧은 수치 사실에 연결한다.
- SIA의 시장자료 안내는 구독 자료의 내부 분석·파생 분석 사용과 원자료 재배포 금지를 설명한다. 이 구현은 구독 자료를 사용하지 않으며, 카드에는 짧은 공개 사실과 원문 링크만 제공한다.
- 카드의 `발표시각`은 WordPress `date_gmt` 메타데이터다. 카드 본문에 별도 공개시각 근거가 확인될 때까지 기사 수정시각을 발표시각으로 대체하지 않는다.
- 응답은 SIA 도메인·게시물 분류·비교 기간·3개월 이동평균 문구를 모두 통과해야 한다. 불일치/미래시각은 표시하지 않는다. 조회는 리다이렉트 금지, 1 MiB 제한, 20초 시간제한, 3일 쿨다운, 월 12회 원자적 예약 상한을 둔다.
- 관측 원장은 공개 사실의 해시를 ID로 삼아 같은 발표의 재조회 행을 중복 적재하지 않는다. 정정된 공개 본문은 다른 해시로 새 버전이 된다. 당시 알 수 있었던 원문 전문이나 엄밀한 과거 공개시각을 복원할 수 있는 자료는 아니므로 PIT/백테스트 자격은 없다.

## 2026-10-05 공개 발표 파서 대조

SIA 공개 발표는 2026년 8월 세계 반도체 매출을 1,597억 달러로 발표했고, 7월 1,479억 달러 대비 +8.0%, 2025년 8월 654억 달러 대비 +144.3%라고 밝혔다. SIA는 월 매출이 3개월 이동평균이라고 명시한다. 공개 WordPress API 응답(46,894바이트)을 실제 파서로 시험해 게시물 ID `31603`, 발표 메타데이터 `2026-10-05T12:00:17Z`, 기간·금액·비율이 모두 맞는 것을 확인했다. 이 응답은 개발 검증이며 운영 원장 수집 증거가 아니다.

## 제품에서의 의미

세계 산업 매출은 한국 개별 기업의 실적이나 주가와 같지 않다. 미국 제조 생산지수(G.17)와도 서로 다른 관측이다. 두 자료 모두 설명용 카드일 뿐 종목 점수, 시장 체온, 추천 순위, 위험판정, 페이퍼/실계좌 주문 및 등록 연구에 입력하지 않는다.

## 운영 후속 확인

배포 후 국내 마감 유지보수에서 수집된 경우 관리자 운영 화면에서 SIA 실제 요청 수, 성공/실패, 받은 응답량, 새 공개 버전 수, 첫 관측 ID를 확인한다. 첫 행이 보이면 카드의 기간·수치·단위·발표 메타데이터·링크를 SIA 원문과 다시 대조하고, 다음 배포 뒤 같은 ID와 누적 건수를 확인한다. 코드 테스트나 로컬 원장만으로 운영 완료나 2.0 점수를 올리지 않는다.
