# Signal Desk 2.0 관심종목 근거 검토 · 소유자 피드백 기준

2026-10-10 범위 변경: 현재 서비스는 소유자 1인이 사용한다. 이전 버전의 외부 초보 투자자 5명 모집·공통 과업 평가는 완료 조건에서 **제외**한다. 이 문서는 실제 운영 화면의 위험한 오해를 찾아 고치는 체크리스트다. 외부 사용자 이해도나 교육 효과를 측정했다고 주장하지 않는다.

## 운영 사례 고정

- 실제 읽기 전용 운영 화면에서 DART 비교 카드, 자료 부족·기권 카드, 연준 G.17 카드, 기본 시그널과 관점 비교 화면을 확인한다. 자료가 없는 사례를 합성 화면으로 대체하지 않고 미완료로 남긴다.
- 각 화면의 캡처 시각, 서버 버전, 카드 관측시각, 원천 URL·접수번호 또는 관측 ID, 법인·기간·단위, 보존 원문 값을 기록한다. 개인 계좌·보유액·인증정보는 포함하지 않는다.
- 소유자가 실제 사용 중 제기한 문구·배치·해석 문제를 같은 장부에 붙이고, 원문과 화면을 먼저 대조한다. 실제 매매를 검토 과업으로 요구하지 않는다.

## 확인할 오해와 수정

아래 항목은 사람별 점수가 아니라 운영 카드의 사실·문구 확인 기준이다.

| 사례 | 화면과 원문에서 확인할 것 | 위험한 오해 |
|---|---|---|
| DART 비교 | 전년·당년 두 접수번호, 회사 귀속, 금액·단위·기간이 각각 보존 원문과 일치 | 과거 회계 변화를 새 매수 신호로 읽음 |
| 자료 부족·기권 | 빠진 자료와 다음 확인 조건이 화면에 명시 | 기권을 성공 확률 0% 또는 즉시 매도 지시로 읽음 |
| 연준 G.17 | 미국 반도체·기타 전자부품 생산지수의 대상 월과 첫 관측 시각을 구분 | 한국 개별 종목 매수 신호로 읽음 |
| 관점 비교 | 읽기 전용 비교임과 원래 시그널·주문 비영향을 확인 | 토글이 실주문 규칙을 바꾼다고 읽음 |

그 밖에 `근거 %`를 상승 확률로 읽음, 낡은 공시를 현재 호재로 읽음, 신규 매수 후보를 보유분 추가매수 지시로 읽음, 가상 결과를 실계좌 손익으로 읽음은 우선 수정할 위험한 오해다.

## 마지막 5점의 완료 증거

각 대표 사례의 원문 대조 결과와 화면 시각, 발견한 오해, 수정 PR, 배포 뒤 같은 화면의 재확인을 남긴다. 소유자 피드백이 있으면 재현·수정 또는 수정하지 않은 이유를 연결한다. 소유자 피드백이 없었다는 사실만으로 사용성이 좋다고 판단하지 않는다.

네 사례 중 하나가 빠지거나 위험한 오해가 미해결이면 [데이터 확장 장부](SIGNAL-DESK-2.0-DATA-EXPANSION-STATUS.md)의 마지막 5점은 보류한다. 이 5점은 설명의 안전성에 관한 것이며 투자 수익 우위나 등록 헤드라인 판정을 대신하지 않는다. 다른 사용자들의 이해도나 교육 효과를 주장하지 않는다.

결과 기록 형식: `확인일 · 앱 버전 · 사례 관측 ID/접수번호 · 원문 대조 결과 · 위험 오해 · 소유자 피드백 링크 · 수정 PR · 배포 재확인 · 남은 한계`. 개인 계좌·보유액은 기록하지 않는다.
