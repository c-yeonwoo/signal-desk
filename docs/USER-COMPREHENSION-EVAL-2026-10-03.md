# Signal Desk 2.0 관심종목 근거 이해도 평가 절차

상태: **과업과 채점 기준만 고정 · 참여자 결과 없음**. 이 문서는 초보 투자자가 공식 자료 카드와 기본 시그널의 차이를 이해하는지 확인하기 위한 운영 절차다. 투자 수익률이나 교육 효과를 입증하는 실험이 아니다. 실제 평가와 결과 기록 전에는 [데이터 확장 장부](SIGNAL-DESK-2.0-DATA-EXPANSION-STATUS.md)의 사용자 이해도 5점을 더하지 않는다.

## 표본과 사례 고정

- 주식 투자 경력 2년 이하이며 Signal Desk 개발·운영에 참여하지 않은 성인 **5명 이상**을 대상으로 한다. 모집 경로와 제외 인원을 결과에 함께 적는다. 서비스 소유자·개발자의 자체 사용은 표본에 넣지 않는다.
- 진행 전에 동일한 읽기 전용 화면을 고정한다. DART 비교 카드 1개, 자료 부족·기권 카드 1개, 연준 G.17 카드 1개, 기본 시그널과 관점 비교 화면을 선택한다. 실제 카드가 아직 없으면 합성 테스트 화면으로 대체하지 않고 평가를 기다린다. SEC 카드가 운영 준비가 되면 추가 관찰할 수 있지만 5개 공통 과업의 조건을 바꾸지 않는다.
- 각 화면의 캡처 시각, 서버 버전, 카드의 관측시각, 원천 URL·보존 관측 ID/해시, 종목 식별자, 사전등록 상태를 사례 표에 먼저 기록한다. 개인 계좌·보유액·인증정보는 포함하지 않는다. 참여자가 결과를 보기 전에 사례와 정답 요소를 고정한다.
- 모든 참여자에게 같은 순서와 화면을 제공한다. 진행자는 답을 유도하거나 용어를 설명하지 않는다. 한 과업에 최대 3분을 주고, 막히면 `모름`도 허용한다. 실제 매매를 시키지 않는다.

## 공통 과업과 채점

각 과업은 0·1·2점이다. 2점은 아래 두 핵심 요소를 모두, 1점은 하나만 정확히 설명한 경우다. 요소와 반대되는 단정은 해당 과업 0점으로 기록한다. 참여자는 화면의 원천 링크를 열 수 있으며, 진행자는 정답을 알려주지 않는다. 링크를 연 여부도 기록한다.

| 과업 | 참여자에게 읽어 줄 질문 | 2점의 두 핵심 요소 |
|---|---|---|
| 1. 기업 변화 | “이 기업의 매출 변화와 비교 기간을 한 문장으로 설명해 주세요.” | 카드의 전년 대비 방향·크기를 읽는다. 분·반기 3개월인지 사업보고서 보고기간인지 구분한다. |
| 2. 근거의 한계 | “이 재무 카드만 보고 지금 매수할 수 있다고 생각하나요? 이유는 무엇인가요?” | 카드가 과거 회계 변화이지 매수 신호가 아님을 말한다. 발표 당시 기대·주가 반영·실제 공개시각 중 확인되지 않은 것 하나 이상을 지목한다. |
| 3. 업종 범위 | “연준 산업 카드의 수치가 무엇을, 어느 시점에 관측한 값인지 설명해 주세요.” | 미국 내 반도체·기타 전자부품 생산지수라는 범위를 말한다. 표시된 대상 월과 관측시각을 구분한다. |
| 4. 판단 경계 | “관점 비교를 켜면 원래 시그널이나 주문도 바뀌나요? 화면에서 무엇을 비교한 건가요?” | 관점 비교는 읽기 전용이며 원래 시그널·주문을 바꾸지 않음을 말한다. 비교 조건에 따라 후보 설명/목록이 달라질 수 있음을 말한다. |
| 5. 다음 행동 | “자료가 부족해 기권한 카드에서 다음에 확인할 것 하나와 지금 하지 않을 행동 하나를 말해 주세요.” | 카드에 적힌 누락 자료 또는 다음 확인 조건을 지목한다. 자료 부족을 성공 확률 0%나 즉시 매수·매도로 해석하지 않는다. |

별도로 위험한 오해를 기록한다. 예: `근거 %`를 상승 확률로 이해함, G.17을 한국 개별 종목의 매수 신호로 이해함, 기권을 손실 확정으로 이해함. 이 오류는 총점과 별개로 공개하며 숨기지 않는다.

## 실행과 결과 판정

진행자는 참여자 동의를 받은 뒤 답의 요지만 익명 코드 `P01`처럼 기록한다. 이름·연락처·계좌·개별 매매 내역·음성 원본은 저장소에 넣지 않는다. 결과에는 사례 고정 기록, 참가/제외 수, 과업별 0·1·2점 인원, 위험한 오해의 유형과 수, 추가 힌트 없이 답한 비율, 원천 링크 사용 여부, 진행일과 평가자를 남긴다. 평균 점수만으로 성공을 주장하지 않는다.

5점 완료 증거는 **서로 다른 적격 참여자 5명 이상의 동일 과업 기록과 집계가 보존되고, 각 오해에 대한 화면 수정 또는 미수정 이유가 추적되는 것**이다. 점수가 낮아도 평가 자체는 완료될 수 있지만, 이해도가 높다거나 서비스를 쓰면 저절로 학습된다는 주장은 하지 않는다. 개선 효과를 주장하려면 별도 대조 조건과 후속 측정을 사전 등록해야 한다. 이 평가는 투자 수익 우위의 사전등록 look을 대신하지 않는다.

결과 기록 형식: `실행일 · 평가자 · 앱 버전 · 사례 관측 ID/해시 · 모집/제외 인원 · P01~Pnn의 과업별 점수 · 과업별 분포 · 위험 오해 유형/수 · 수정 이슈 링크 · 한계`. 참여자 답변의 식별 가능한 원문은 적지 않는다.
