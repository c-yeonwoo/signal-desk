# SIG-29 · 운영 확인과 공통 기준

기준 main `7b8fee69f478535e8b6a349e62c93a0fa24d886a`. 운영 화면에서 이미 서비스/데이터/연결/연구가 구분되어 있었다. 그 군집화를 새 성과로 세지 않는다. 남은 문제는 작은 섹션 제목과 붙은 설명, 반복 제목/긴 재확인 안내, 참고 대기와 직접 확인 항목의 시각적 경쟁이었다.

## 변경 범위

- 관리자 제목과 본문 간격, 항목 경계와 행동 버튼을 정돈한다. 문제·영향·확인 시각·다음 확인은 기본 화면에 남기고 중복 상태 설명/재조회 기록만 접는다. 자동 큐·연구 표본 대기는 별도 참고로 접는다. 원래의 항목 계산·분류·배지·이동은 그대로다.
- 공통 버튼의 native disabled를 시각적으로 구별한다. 스타일만으로 새로운 권한이나 동작 차단을 구현한 것이 아니다.
- 현행 indigo 토큰·분리 자산·현재 메뉴와 충돌하던 DESIGN.md를 현행 구현으로 정정하고 미리보기 sidecar를 보존한다. 색/브랜드/서체를 새로 선택하지 않았다. 기존 실계좌 초안/저장/사전점검·차트 보존 규칙을 유지한다.
- 실제 해외 화면의 최신 종가503/503이지만 계산 이력502종목인 상황을 확인했다. 이때 ‘종가 누락’으로만 설명하던 문구를 ‘가격·계산 이력 확인 필요’로 정정한다. 계산·보류 판정은 바꾸지 않는다. 몇 달 흐름 설명의 옛 ‘시그널 첫 화면’도 현재 ‘오늘’ 메뉴로 바로잡는다.

## 검수·한계

격리된 실제 앱과 합성 health 응답으로 PC/390px 모바일, 긴 상태문장, 원천 요청 실패/가격 지연, 재조회 설명 펼침, 연구 대기 분리, 정상, HTTP503 조회 실패를 확인했다. 모바일 페이지 가로 넘침은 없었고 원래 경로를 유지했다. [PC](../.impeccable/review/pd5/desktop.png)·[모바일](../.impeccable/review/pd5/mobile.png)·[실패](../.impeccable/review/pd5/mobile-error.png)·[출처](../.impeccable/review/pd5/captures.json).

관련235테스트 통과. 실제 관리자 렌더러의 영향/시각/다음 단계, 자료/연결/연구 이동, 자동 대기를 운영 숙제로 만들지 않는 기존 경계를 포함한다. Impeccable 기계 검사에는 전체 HTML의 기존 온보딩·클리핑·일회성 척도 등 경고가 남아 있으며 전체 경고0/접근성 인증을 주장하지 않는다. 별도의 코드·마감 리뷰, 정확한 HEAD CI·머지·배포와 로그인 운영 화면 확인은 runtime 전달 기록으로 구분한다.

API·가격 수집·엔진·순위·가중치·주문·기업행사/연구 원장은 변경하지 않는다. 운영 캡처는 private runtime에만 저장한다. 완료되면 디자인5/6이며 통합40% 유지다. 실제 소유자 수용과 수익 개선은 추정하지 않는다.
