# SIG-30 · 최종 조작·반응형·로딩 확인

기준 main `ddcb920ee38986611f8a615c655ab816659c13e1`. 새 기능·리브랜딩을 추가하지 않고 PD1~PD5에서 바꾼 핵심 흐름을 확인한다. 기존 사용자 피드백에 대한 배포 검수와 소유자의 실제 수용을 구별한다.

## 확인한 결함과 변경

상단 알림·계정·로그아웃은 클릭 가능한 span이라 Tab 키로 접근할 수 없었다. 동일 핸들러를 가진 type=button으로 바꾸고, 계정 버튼 이름·헤더 글꼴/높이를 보존했다. 버튼·링크·접힌 설명에 키보드 포커스를 표시한다. 독립 리뷰에서 선택된 세그먼트의 배경/안쪽 포커스가 같은 색이라는 반박을 받아 흰색 안쪽 테두리로 수정했다. 실제 브라우저 계산값은 배경rgb(36,60,219), 포커스rgb(255,255,255)다.

시그널·가격 수집·API·차트·매매·연구 코드는 바꾸지 않는다. 실제 로그아웃·계좌 변경·주문은 검수에서 실행하지 않는다. 합성 환경에서 알림 열기만 실행했고 그 환경의 POST는405로 차단돼 있다.

## 검수 범위

- 실제 정적 앱의 PC와390px 모바일 반응형: 긴 한글 종목명, 목록→상세→목록, 가격/시그널 두 선·B/S·3모드·기업 근거, 내 투자 표의 내부 스크롤과 접힘을 확인한다. [PC 키보드](../.impeccable/review/pd6/desktop-keyboard.png)·[모바일 종목](../.impeccable/review/pd6/mobile-stock.png)·[모바일 투자](../.impeccable/review/pd6/mobile-investment.png)·[출처](../.impeccable/review/pd6/captures.json).
- 합성 앱에서 내 투자→Tab→알림, Enter 열기→닫기→원래 버튼 포커스 복귀, Tab→계정→로그아웃을 확인했다. 로그아웃은 누르지 않았다. 선택된 차트 모드의 포커스도 직접 확인했다.
- 관련25테스트와 최종 native button 회귀1테스트를 통과했다. 실제 시세 결측/지연·응답 경합·내 투자 실패/빈값 구별은 기존 실제 함수 테스트와 PD2~PD5의 격리 브라우저 증거로 이어 확인하며, 같은 검사를 새 엔진 개선으로 세지 않는다.
- 실제 iOS/Android 장치가 연결돼 있지 않다. 좁은 뷰포트와 코드 확인을 실제 휴대폰의 터치·안전영역·소프트웨어 키보드 인증으로 부풀리지 않는다. Mobile Native 스킬의 하드웨어 주의사항은 이 한계로 남긴다. 확대 금지나 user-agent 분기는 추가하지 않았다.

## 동일 조건 로딩 관측

Web Perf 도구는 기존 전용 Chrome 프로필 점유로 연결 실패했다. 다른 브라우저 종료·프로필 변경·추가 설치는 하지 않았고 정식 trace/Lighthouse/Core Web Vitals 인증은 미완료다. 대신 자체 격리 페이지에서 브라우저 PerformanceObserver와 Performance API의 관측을 **DOM output으로 표시**해 읽었다. 그 계측은 운영으로 배포하지 않는다.

같은 Chrome·desktop1386·warm cache·동일 합성 API 응답으로 전후3회씩 새로고침했다. 초기 로드1회는 기준선 워밍에만 썼으며 원시 표본은 회사 runtime의 `pd6/perf-observations.json`에 보존한다. 변경 전 HTML SHA256은 `b41b6d2ffe76050da7261c20c8c09798f0051eaa2257b4cfeab4d8d113f3344d`, 후는 `20e7ae8124dcaf8c69ae919100d1ecb558e613b654ac147f9afa58e7de5b0dbd`다.

## 완료 판정

Impeccable의 최종 검수와 독립 코드리뷰, 정확한 PR HEAD CI·머지·운영 자산 해시 및 로그인 실제 화면 확인이 갖춰진 뒤 이번 유한 디자인 범위를6/6으로 닫는다. 실제 사용자 수용·휴대폰 하드웨어 인증·정식 성능 trace·연구 수익성 채택을 완료했다고 쓰지 않는다. 남은 전체 HTML의 기계 검사 경고를 지우기 위한 끝없는 미세수정도 추가하지 않는다. **통합 로드맵40%는 유지**한다.
