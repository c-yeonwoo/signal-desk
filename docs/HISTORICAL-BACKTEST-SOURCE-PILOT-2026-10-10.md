## 첫 개발 재생: 가격 부분만

`krx_price_replay_pilot.py`는 위 네 KRX ZIP의 원문 해시와 전 거래일을 먼저 검증했다. 2026-06-01–06-30의 **21세션**마다 그날 종가가 확정된 뒤의 시총 상위 200으로 현재 공용 엔진의 *가격 부분*을 재생하고, 다음 정규장 시가 진입→h5/h20 종가의 탐색 경로를 계산했다. 252일 모멘텀을 위해 연속 **253세션**을 요구했다. 후보 슬롯 4,200개 중 연속 이력이 없는 66개를 기권 처리해 4,134개 출력 행을 얻었다. 6월 판단의 결과 가격도 모두 보호 시작 전인 7/31까지만 읽었다. 원천 ZIP·코드 해시를 포함한 로컬 결과 `krx-price-only-development-2026-06-v1.json`은 SHA-256 `2dce89c9c66d582b9f4422ef4b0f725377c16dfa4c9754d179c92190a9057da9`이며 두 번째 실행 파일과 바이트 단위로 일치했다.

진단상 BUY/STRONG_BUY **103행은 고유 13종목**에서 반복됐다. 0.25% 왕복 비용 *가정*으로 다음 시가→h5 종가 평균은 −2.08%, 해당일 저장된 종목군 평균 대비 +0.65%p였다. h20 평균은 −20.95%, 같은 종목군 대비 −10.64%p였다. 이 큰 하락은 **가격 전용·21일·중첩 보유·13종목 집중·기업행사/배당/실체결 미검증**의 탐색 수치다. 특히 매수 103행 중 2행은 h20 동안 KRX 상장주식수 변화가 1%를 넘었다. 이를 현행 8팩터 시그널의 성적, 독립 거래 103건, 매매 규칙 변경 근거 또는 등록 연구의 look으로 해석하지 않는다. 단, 가격 모멘텀만 보면 급등 뒤 반전 구간에서 위험이 커질 수 있다는 **검증할 실패 가설**은 남긴다.

## B 수준으로 올리기 위해 아직 필요한 것

1. DART 목록의 `stock_code`–`corp_code`–`rcept_no`를 고정하고, **당시 접수번호의 원문/원본 XBRL**에서 재무 수치를 추출한다. 정정본은 정정 접수 이후에만 사용한다. 접수 시각이 없으면 그날 마감 판단에 넣지 않고 다음 정규장부터 사용한다. 현재 OpenDART는 [2026-10-11 18:00까지 원문·고유번호 API 점검을 공지](https://opendart.fss.or.kr/)했고, 목록 API는 실제 성공했다. 목록만으로 재무 팩터를 적격으로 만들지 않는다.
2. KRX 종목행의 액면분할·배당·증자 등 기업행사와 수정 전후 가격을 별도 대조한다. 상장주식수 변화가 없다는 사실도 모든 행사 부재의 증거는 아니다. 수급·공매도 이력이 검증되지 않으면 8팩터 결과라고 부르지 않고 결측/기권한다.
3. 본 개발 구간에서 규칙을 고른 뒤에는 *별도의 사전 고정 평가 구간*을 열고 날짜별 우주·진입 가능 가격·비용·하방 꼬리·단순 기준 전략을 비교한다. 기존 8/05 이후 등록 보호 구간의 집계 결과나 운영 가중치·실주문 정책은 열거나 바꾸지 않는다.
4. 미국은 기존 과거 구성종목이 없어 현재 509종목을 예전 날짜로 되메우지 않는다. SEC 자동 요청은 실제 운영 연락처 확인 전 열지 않는다.
