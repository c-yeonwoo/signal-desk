# 금융위 권리일정 API 실측 검수 · 2026-10-18

## 결론

로컬 `DATA_GO_KR_SERVICE_KEY`로 인증·과거 조회에 성공했다. 기존의 **서비스키 미확인은 해결**됐다. 수집기와 날짜·회사 구분 검수 경로를 추가했지만, 이 API의 특정 기준일 조회 완료를 기업행사 전수 인증으로 쓰지는 않는다. 새 모델 학습·보정·210경로 성과는 아직 미실행이며 통합 진행률은 **40/100**이다. 운영 판정·주문·가중치와 동결 계약은 바꾸지 않았다.

공식 [금융위원회 주식권리일정정보](https://www.data.go.kr/data/15059609/openapi.do)의 보존된 Swagger에 있는 `getRighExerReasSche_V2`만 호출했다. 최초 전체 조회는20초 타임아웃으로 끝났고, 이후45초 한도와 작은 양성 대조 조회로 인증·응답을 확인했다. 키를 로그·URL 장부·ZIP에 저장하지 않으며 다른 호스트로 전달하거나 리다이렉트를 따르지 않는다. 유료 구매·운영 환경변수 변경은 없다.

## 실제 응답과 원문 대조

추가 양성 대조인 삼성전자2023-12-28은0행이었다. 이를 배당·분할이 없다는 인증으로 바꾸지 않았다. 정확한 발행사 코드는 카카오03572·삼성전자00593·현대중공업지주26725·포스코00549로 검수하되, 이5자리 코드는 **보통주 ISIN/주식종류 인증이 아니다**.

KIND·IR 비교 근거는 이전 [날짜 처리 구현 보고서](KR-NET-ALPHA-ACTION-CLOCK-IMPLEMENTATION-2026-10-18.md)의 고정 원문을 재사용했다. 새로운 시각·정정 이력을 만들어 넣지 않았다. 삼성전자 응답의 지급 시작/종료 구간은 원문대로 보존하며 종료일의 법적 의미는 확인되지 않았다.

## 보존·재현

모든 파일은 무시된 로컬 `data/research/` 아래에 있고 기존 파일을 덮어쓰지 않는다. JSON 목록은 [동반 인덱스](kr-net-alpha-fsc-rights-2026-10-18.json)에 해시로 고정했다. ZIP에는 실제 응답·정책·실행 당시 코드·키가 제거된 요청 장부가 들어 있다.

```bash
# 코드가 바뀌면 새 출력 이름을 사용한다. 인증 실패와 빈 결과는 구분한다.
.venv/bin/python -m scripts.measure.kr_net_alpha_fsc_rights \
  --output data/research/<새 탐침>.zip --report data/research/<새 탐침>.json

# 고정된 여섯 대조 쿼리. 같은 응답은 해시를 확인한 캐시에서 읽는다.
.venv/bin/python -m scripts.measure.kr_net_alpha_fsc_rights --crosscheck \
  --output data/research/<새 대조>.zip --report data/research/<새 대조>.json

# 추가 API 요청 없이 원문·보고서 해시와 회사/날짜 역할을 검수한다.
.venv/bin/python -m scripts.measure.kr_net_alpha_fsc_rights \
  --inspect data/research/kr-net-alpha-fsc-rights-crosscheck-2026-10-18-v1.json \
  --report data/research/<새 역할 검수>.json
```

누적 행사 요청은 **170/400**, 가격·기본정보 요청은 **810/1,200**이다. 실패한 최초 탐침도 행사 예산에 포함했다. 마지막 역할 검수는 추가 요청0회다. API 응답·원문·장부에서 실제 키가 남지 않았는지 별도로 검사했다. 회사 부분 일치, 액면가 중복, 페이지 부족·총건수 변경과 인증키 유출 방지를 포함한 원천 회귀 검사20개가 통과했다.

## 남은 자료 관문과 다음 작업

이번 API는 기준일·회사로 조회한다. 보존된 명세와 응답만으로는 다음을 증명하지 못한다.

- 전 기간 효력일 기준 전수성과 모든 필수 행사 종류의 포괄 범위.
- 원본이 언제 공개됐는지와 당시 존재했던 정정 버전.
- 개별 행의 보통주/우선주 연결, 분할 비율·배당금, 실제 지급·주식 교부 완료.
- KIS와의 독립성. 양쪽 권리일정이 한국예탁결제원 자료라 단순 일치를 독립2원천으로 세지 않는다.

따라서 현재 검수는 **역할별 원천 대조에 채택**, 학습용 전체 범위 인증과 매매 승격에는 **미채택**이다. 신규 인증서를 입력하지 않았으므로 준비도v10의 학습0/180·보정0/80·평가0/300, 285증권·1,688미인증 범위는 그대로다. 같은 준비도 계산을 무의미하게 다시 돌리지 않았다.

다음은 이 응답과 기존 KIND 접수번호를 행사별로 연결하고, 공식 발행·상장 원천의 주식종류·수량·정정 범위를 검수하는 일이다. 기존 허용 계약 안의 수집·검수는 **Sol high**로 진행할 수 있다. 원천 간 사실 충돌이나 범위 인증 기준 자체를 바꿔야 한다면 **Astra high 설계 판단**으로 분리한다. 새 거래일을 기다리는 문제가 아니며 조건을 낮춰 학습을 열지 않는다.
