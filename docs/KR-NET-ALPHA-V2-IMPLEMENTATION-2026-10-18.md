# 국내 v2 대상과 라벨 구현 및 실제 원천 검사

2026-10-18 KST. [거래 가능 대상·시가 결손 계약](KR-NET-ALPHA-TRADABILITY-2026-10-18.md)의 원천 로더·U 감사·경제적 라벨 빌더·학습 준비 관문을 구현하고 실제 보존 자료에 실행했다. **현재 판정은 `blocked_data`, 채택 판단은 `not_evaluable_data_gate`다. 실제 모델 학습·보정·성과 백테스트는 실행하지 않았다.**

## 구현한 동작

- 부모와 v2 계약의 커밋·해시, 기존 가격·종목별 ISIN·수집 장부를 검증한다. 미래 라벨을 입력받지 않는 함수로 당일 거래·알려진 정지·253시장 세션·단위 조정 조건을 평가한다. 출처 없는 주식수 변경을 분할로 처리하지 않는다.
- 검수 묶음의 실제 원문과 리뷰 파일 바이트를 해시·기간·증권·행사 종류·사건 목록에 연결한다. `complete` 문자열이나 임의 수익률을 넣어 통과시키는 입력은 제공하지 않는다. 원문을 해석한 검수자의 판단까지 해시 검사가 독립 증명하는 것은 아니다.
- e=t+1, x=t+6의 원시 가격과 확인된 분할·배당·확정 현금교환·후속 증권을 사용해 경제적 라벨을 만든다. 미진입·청산 불가·원천 누락·가격 없는 권리를 구분하고 수익은 null로 남긴다. 복잡한 후속 행사 사슬·동시 권리 순서가 미확정이면 계산을 보류한다.
- 학습·보정 마감 뒤에만 알려진 권리를 `행사 없음`으로 처리하지 않는다. 학습 날짜 전체의 라벨이 완전할 때만 표본을 만들고, 준비 날짜 수를 실제 표본에서 집계한다. 평가 달력은 학습 결손 마스크로 줄이지 않는다.
- 실제180/80일이 있으면 기존 수치 코어의 두 회귀와 보정으로 연결한다. 기존 모델 경로가 있으면 재학습을 거부한다. 현재 자료에서는 관문이 닫혀 모델 파일을 생성하지 않았다. **210경로 상태형 실행기·채점은 아직 구현/실행하지 않았다.**

원문과 결과는 로컬 `data/research/`에만 저장한다. 중간 산출물도 보존하고 최종 전체 감사는 재현 가능한 gzip으로 압축한다. 운영 볼륨·시그널·주문과 연결하지 않는다.

## 실제로 확인한 사실

### 아시아나항공 공개 시각

2021-05-26의 공식 KIND 검색 목록에서 접수번호 **`20210526000293`**, 공개 시각 **15:29**를 확인했다. 기존에 보존한 정지 원문의 **문서번호**는 `20210526000995`다. 두 번호는 역할이 다르다. 원문의 효력 시각과 목록의 공개 시각을 따로 보존했다. 분 단위 공개시각은 해당 분의 마지막 순간부터 사용하므로 이 사례는 t의15:30 마감 전에 알려진 정지다.

실제 U 감사에서 그날 `020560 / KR7020560009`가 `known_halt`로 제외됐다. 날짜가 없는 일반적인 정지 추정이나 오늘의 정지 목록을 과거에 적용한 결과가 아니다. 후속 정지 해제 범위까지 완전히 검증한 것은 아니므로 이 개별 사실로 전 기간 범위 인증을 만들지 않았다.

## 재현과 다음 작업

```bash
.venv/bin/python -m scripts.measure.kr_net_alpha_v2 \
  --evidence data/research/kr-net-alpha-v2-asiana-evidence-2026-10-18-v1.json \
  --output data/research/kr-net-alpha-v2-readiness-2026-10-18-v5.json.gz \
  --fit-output data/research/kr-net-alpha-v2-model-2026-10-18-v1.json
```

같은 원문·계약·구현이면 같은 결과 파일 해시를 확인하고, 다른 결과로 기존 파일을 덮어쓰지 않는다. 새로운 원천은 새 감사 버전으로 만든다. 수집기는 읽기 전용이며 폼/목록 조회도 누적 요청에 센다. 같은 양성 대조를 반복해서 기간 인증을 올리지 않는다.

최종 전체 감사 SHA256은 `dcc3bbd766a949fcad4aec2db35373329f9895a3c543b7d2e8b6b9d1ca98a4f1`이다. 실행기·라벨 코드의 내용 해시도 그 안에 묶었으며 최종 구현과 대조했다. [기계 판독 요약](kr-net-alpha-v2-readiness-2026-10-18.json)은 전체 감사의 상태·분모·개별 사실·요청 수를 옮긴 것이고 새로운 성능 결과가 아니다.

검수 묶음 JSON의 스키마는 `net-alpha-reviewed-evidence-v1`이다. `documents`는 로컬 연구 파일의 상대 경로·바이트 해시, ZIP이면 멤버·ZIP해시를 포함한다. `facts`는 사건/버전ID·ISIN·효력시각·공개일/시각·원문 해시·본문 위치를, `certificates`는 기존 `CoverageCertificate`와 원문/종류별 범위·정정/사건 대조 리뷰의 실제 파일을 연결한다. 부모 계약의 기간·종목·종류와 다르면 거부한다. 공식 목록의 의미와 검수 내용은 수집자가 확인해야 하며, 코드가 빈 응답에서 리뷰를 생성하지 않는다.

다음 필수 작업은 **공식 효력일·권리락일 목록의 접근/기간 범위를 확보하고, 학습에 필요한 종류별 원문·정정 대조를 검수 묶음으로 만드는 것**이다. 일괄 배당 조회는 그중 일정 수집 비용을 줄이는 경로다. 현재 부족한 가격 외 증명을 코드로 꾸며 학습을 열 수는 없다. 새 거래일 관측을 기다릴 일이나 추가 전략 재설계는 아니다. Sol high로 원천 검수를 이어가며,180/80일 관문이 열린 뒤에 한 번 학습·보정하고210경로 실행기로 진행한다.
