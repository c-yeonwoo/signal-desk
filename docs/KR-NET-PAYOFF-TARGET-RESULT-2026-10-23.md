# 비용 후 이익·손실 분리 후보: 미채택

고정 후보 `kr-net-payoff-two-head-h5-v1`을 구현하고 기존 자료로 실행했다.
**채택하지 않는다.** 정해 둔 계좌 비교의 기계 판정은 `inconclusive_data`다.
100계획 계좌 중20완결·80미완결로5위상 평균을 확인할 수 없었다.
완전한 선정 진단과 완결 계좌에서도 개선을 뒷받침하지 못했다.
수익성 악화를 관측한 것과 전체 계좌 비교의 자료 미달을 함께 기록한다.

## 무엇을 실행했나

[사전 설계](KR-NET-PAYOFF-TARGET-DESIGN-2026-10-23.md)의 이익 기여 G와 손실 부담 L을
각각 학습하는 두 Poisson 손실 트리 모델을 구현했다. 순위는 G−L이다.
깊이2·반복50·날짜 동일 학습 가중,120bp 목표·μ>0 신규 진입을 고정했다.
동일 비선형 단일 순수익 모델·원Ridge·12개월 모멘텀과 비교했다.
시장 회귀·추가 보정·문턱 탐색·뉴스·원천 수집은 실행하지 않았다.

4개 expanding 학습과 최종4~9월 학습을 합해 **20fit**, 역사 실행 묶음1회다.
내부6~9월 선정은160코호트 경로 중90완결·70미완결이다. 최종10/2~12/11 계좌는
5팔×5위상×4비용/체결 조건으로100계획 경로를 평가했다.
코호트는 동일 금액의 h5 수익이고, 계좌는1,000만원·정수 수량·실제 자기 NAV·만기 매도·
같은 종목 재매수 비용·T+2·잔량 재시도를 포함한다. 둘의 수익률은 서로 다른 지표다.

## 결론과 반영 범위

이익과 손실을 나누는 구조는 해석 가능한 출력을 만들었지만, 이번 자료에서는 수익성 개선을
입증하지 못했다. 단일 순수익 트리보다도6월 선정과 기본 완결 계좌 성과가 나빴다.
새 목표만으로 학습 입력의 선정 정보나 표본 안정성이 좋아지지는 않았다는 반례다.
14개 특성의 모든 정보가 무가치하거나 비선형 모델 전체가 실패했다는 일반화는 하지 않는다.

**운영 반영0, 후보 미채택, 통합40/100 유지**다. 연구 구현과 결과만 보존한다.
원천 결손을 없애려고 취소한 기업행사 조사를 재개하거나, 비용·문턱·기간을 바꿔
같은 후보를 다시 살리는 작업은 하지 않는다. 다음 설계 검토가 필요하다면 Astra high에서
학습 표본과 입력 정보의 유효성을 먼저 다루고 새 후보의 실행 계약을 정해야 한다.
기존 단순 대조도 이 결과만으로 운영에 올리지 않는다.
