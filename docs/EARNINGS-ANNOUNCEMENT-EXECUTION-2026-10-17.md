# 실적 기사 확인 직후 진입 · 호가 실행 실험

## 가격 결과를 보기 전 고정한 별도 실험

기존 `EARNINGS-FAST-ENTRY`의 **최초 공개·당시 예상치 버전·실계좌 정산비용 인증** 계약은 유지한다. 이번 실험은 그 자료가 전부 인증됐다고 주장하지 않는 **조건부 역사 재구성**이다. 이미 본 AAPL 접근 검사 5초 두 구간은 수익 결과를 보지 않았으며 사건 선택에 쓰지 않는다. 2024/2025 결과를 새 확인 표본으로 재사용하지 않는다.

- 모집단: 기존 AAPL/MSFT/GOOGL/AMZN/META/NVDA/JPM/XOM, 기존 보존 EPS 원문에 있는 **2022년 32발표(개발), 2023년 32발표(확인)**. 각 회사 4발표/년을 모두 결손 원장에 남긴다. 날짜와 회계기간만 기존 원문에서 취한다. 성과를 보고 회사·기간을 교체하지 않는다.
- 판단 입력: 해당 발표일의 Alpaca/Benzinga 실적 속보 제목에 실제 EPS와 예상 EPS가 함께 명시된 기사. `EPS … Beats/Misses/… Estimate`의 직접 비교만 결정론적으로 읽는다. 사전 전망·과거 회상·복수 회사 제목은 쓰지 않는다. 같은 발표의 서로 다른 EPS 값이 충돌하면 결손이다. 현재 vendor EPS를 당시 예상치로 소급하지 않는다. 제목에 없는 GAAP/조정 기준과 원본 버전의 불확실성은 별도 제한이다.
- 입력 가용 시각: `max(created_at, updated_at)` + 처리 30초. 최초 공개 시각과 수정 시각을 혼동하지 않는다. 그 회사 발표일에서 벗어난 기사·수정은 이 실험의 직후 진입 입력이 아니다. 이 시각도 과거의 실제 API 수신 기록은 아니므로 strict PIT 적격은 false다. Meta의 발행사 배포 원문 8건은 독립 공개 시각 대조용이며 결과에 맞춰 입력 시간을 앞당기지 않는다.
- 경로 A: 확인된 입력 가용 시각 이후. 미국 현지 04:00~19:00에만 진입해 60분 보유를 20:00 전에 종료한다. 경로 B: 입력이 준비된 뒤 처음 오는 **정규장 개장+60초**. 장전 발표면 당일이고 장후 발표면 다음 거래일이다. XNYS 휴장·DST·조기마감을 사용한다. 경로별 결과를 합산하지 않는다.
- 선택: 양의 실제·예상 EPS이고 예상 대비 **5% 이상 상회**. 경로별 거래 날짜마다 결정 시각이 빠른 적격 사건 하나만 선택, 동시이면 회사명 순. 미래의 그날 다른 발표 때문에 과거 선택을 바꾸지 않는다. 해당 날짜의 다른 사건과 선택 안 된 사건도 원장에 남긴다.

## 실행 · 대조 · 실패 처리

고정 자금 $10,000, 매매당 가용 현금 1/6 이내, 무차입·정수 주식이다. 결정 시각 이후 첫 유효 SIP 호가의 ask로 수량과 **ask×1.003 지정가**를 정하고, 적어도 1초 뒤 첫 유효 호가에서 ask가 지정가 이내일 때만 체결 모델을 적용한다. 진입은 ask, 청산은 실제 진입 시각+60분 뒤 bid다. 수수료를 포함한 현금 한도를 넘기지 않는다. 스프레드를 다시 비용으로 더하지 않는다.

5초 원문 안에서 정확한 나노초 비교를 한다. 양의 bid/ask·잔량, bid≤ask, 거래소/조건 코드를 확인하고 잠금/역전·비정상 호가는 제외한다. 잔량은 역사 단위 변경의 소급 적용 여부가 미확인이므로 **원시 수량을 주 수로 그대로 취하는 보수적 상한**이며 과거 round lot에 100을 임의 곱하지 않는다. 호가에 표시된 잔량도 실제 체결을 보장하지 않는다. 지정가 밖·확인 가능한 잔량 부족은 미체결/부분체결로 구분한다. 자료가 없거나 부분 페이지에 유효 호가가 없으면 미체결 0%가 아니라 `missing`이다. 청산 자료가 없으면 포지션을 장부에서 지우지 않으며 전체 경로의 순수익은 null이다.

- 대조: 현금, 모든 실적 발표 매수(각 날짜 최초 확인 사건), EPS 선택과 같은 결정 시각의 SPY 매수. 종목별·분기별 손익, 거래당 수익·양의 거래 비율·계좌 수익·최대 낙폭과 비중 집중을 구분한다. 고정 생존 회사 패널이므로 전 시장 일반화는 하지 않는다.
- 비용: 편도 **10bp**(현재 계좌 응답을 참고한 명시적 가정), 편도25/50bp 스트레스. 역사 실정산 순수익은 계속 null이다. 수수료·제비용을 모두 포함한 실제 요율이라고 부르지 않는다. 모든 경로에서 같은 요율을 쓴다.
- 실행 스트레스: 추가 지연60초, 주문수량 절반, 전량 미체결. 이를 여러 새 최적 전략으로 고르지 않는다. 지연된 전략의 개장 기준과 입력 시간도 함께 늦춘다.
- 결손: 64사건 모두의 회사/날짜/원문/기사 선택/제외/진입/청산/대조 결손을 기록한다. 누락 사건만 빼고 완성된 전략 수익으로 보고하지 않는다. 완전한 하위 표본의 기술 통계를 내면 전체 성과와 명확히 구분한다.

## 결과를 보기 전 채택 기준

확인 2023년 기준 최소12거래·6회사·각 분기2거래, 모든 선택 사건의 진입/청산/짝 시장 대조 완전성, 양의 순수익과 현금·SPY·모든 발표 대조 우위, 네 분기 양의 순수익, 편도25bp·추가60초·절반체결에서도 양의 순수익이 모두 필요하다. 모두 만족해도 역사 자료의 실제 가용 시각·주문 권한·정산비용·독립 모의 관측과 사용자 승인이 확인되기 전 **실전 채택은 하지 않는다**. 실패하면 해당 고정 정책을 기각하고 같은 확인 기간에서 재튜닝하지 않는다. 자료 부족이면 성능 실패와 구분해 채택을 보류한다.

등록 헤드라인·가중치·기존 시그널/주문·R11~R16은 변경하지 않는다. 통합 진행률은 전체 완료 관문 증거 없이 올리지 않는다.

## 가격 조회 전 원천 검수에 따른 명시적 보충 · v2

64일·1,648기사와 다음 페이지 1회를 먼저 확보한 뒤, **아직 진입·청산 가격 결과를 보기 전** 규칙을 보충했다. 원래 계획과 최초 cohort v1 해시는 보존한다. `Estimate`/`Est.`와 `Beats`/`Misses`/`vs`는 같은 직접 EPS 비교 표기로 정규화한다. `EPS Excluding Significant Items`는 명시적 조정 EPS로 구분한다. 숫자 비교가 없는 기사에 현재 vendor 예상치를 붙이지 않는다.

이 별도 실험의 정책은 **완전히 조회한 해당 뉴스 피드에서 직접 비교 근거가 있을 때만 매수**다. 회사·분기의 실제 실적 보도가 있지만 비교 수치가 없거나 `May Not Compare`면 `comparison_unavailable_abstain`으로 기록한다. 이는 EPS가 나쁘다는 판정도, 원래 최초 공개/정산 검증의 완료도 아니다. 전체 발표 대조군은 해당 회사·분기의 EPS 결과 제목 또는 실적 요약 제목의 확인 시각을 쓰고, 이 전략의 관망 사건도 제외하지 않는다. 실적 보도 자체가 없거나 원문/페이지/공개·수정 시각이 불완전하면 여전히 결손이며 성과는 null이다. 고정 회사별 실적 제목 접두부를 사용하고 다른 회사·사전 전망·서로 충돌하는 EPS 비교는 허용하지 않는다.

이 보충은 가격 결과에 맞춘 수익 최적화가 아니라 입력 형식·관망 정책의 명시다. v2 계획으로 모집단을 다시 저장한 뒤 호가를 수집한다. 채택 표본수·비용·분기·스트레스 문턱은 낮추지 않는다. 현재 조회되는 과거 피드가 당시 모든 기사와 동일했다는 인증은 없으므로, 이 **피드 한정 조건부 수익**과 최초 계약의 미확인 실제 정산 수익을 끝까지 별도로 표시한다.
