# 원예측 학습구간·특성 기여 점검과 날짜 내 학습 후보

## 결론

**후보 기각. 운영 엔진 변경 없음.** 새 모델을 한 번 학습하고 140/140경로를 완결했다.
기존 모델의 시장 반등 기대가 낙관 예측에 기여하는 것은 확인했지만, 이를 제거해 재학습한
모델이 더 좋은 종목을 고르지는 못했다. 기존 비용·보정·진입 조건 아래에서는 전부 현금이었다.
낙폭 0을 성능 개선으로 세지 않는다. 원 모델이 옳다는 결론도 아니다.

여기서 원모델은 **2026-10-17의 연구용 R3 Ridge 예측 모델**이다. 운영의 강력매수 점수
엔진 전체를 재학습하거나 검증한 결과가 아니다. 기업행사 조사·Paperclip·새 원천 수집·
실주문은 재개하지 않았다. 통합 로드맵 **40/100 유지**.

행 수가 많은 날짜를 중복 가중한 코드 오류라고 설명하지 않는다.

## 낙관 예측은 어디서 생겼나

원래 `design × coefficient`의 합을 예측과 대조했다. 계수 크기만으로 중요도를 매기지 않았다.
평가 49일 중 **최근 5일 하락한 원래 상위6 후보 236행**의 평균 기여는 다음과 같다.

| 원예측 구성 | 예측에 더한 평균값 |
| --- | ---: |
| 매출 증가율 | +0.4483%p |
| 20일 평균가격과의 거리 | +0.4171%p |
| 시장의 최근 20일 움직임 | +0.4046%p |
| 장기 모멘텀 | +0.2911%p |
| 절편 | +0.2730%p |

나머지 특성까지 합친 원예측은 **+1.7613%**, 관측된 후행 가격수익은 **+0.7873%**다.
평균 오차 +0.9740%p이며 이것이 모든 하락종목이나 개별 손실을 설명하지는 않는다.
‘시장 하락 + 평균가격 하회’ 두 입력이 합쳐 +0.8217%p의 기대를 더한 기계적 경로를 확인했다.

원 `market20` 계수는 표준화 단위당 −0.00868949다. 이 변수는 KOSPI가 아니라 당일
적격 종목들의 20일 수익률 중위다. `distance_ma20` 계수는 −0.00369067이므로 가격이
평균 아래로 내려가면 예측을 올리는 방향이다. 새 학습에서 시장 계수는 사실상 0,
MA20 거리 계수는 −0.00041060이 됐다. MA20의 원래 학습 관계에는 날짜 공통 움직임이
상당 부분 섞여 있었다는 증거다. 반면 매출 증가율 계수는 +0.00238741→+0.00236529로
거의 그대로였고, 단기 `ret1`의 음수 계수는 더 커졌다. 공통 시장 성분을 빼도
종목별 단기 반등을 찾는 관계가 사라지는 것은 아니다.

특성끼리 상관이 있으므로 이 분해를 인과적 중요도나 독립적인 수익 원천으로 해석하지 않는다.
이 주의는 [scikit-learn의 선형 계수 해석 문서](https://scikit-learn.org/stable/auto_examples/inspection/plot_linear_model_coefficient_interpretation.html)와 같다.

### 학습기간의 반등 관계와 평가기간의 차이

아래는 학습일별 시장20일수익과 그날 종목들의 후행5일 평균수익 간 상관이다.
표본이 겹친 기술통계이며 유의성 검정이 아니다.

| 학습월 | 날짜 | 후행5일 평균 | 상관 |
| --- | ---: | ---: | ---: |
| 4월 | 21 | +0.7634% | −0.678 |
| 5월 | 20 | +0.1203% | −0.613 |
| 6월 | 19 | +0.4271% | −0.329 |
| 7월 | 23 | −1.3582% | +0.092 |
| 8월 | 21 | +0.5388% | −0.751 |
| 9월 | 12 | +1.9143% | −0.550 |

한 번의 반등만 잘못 배운 것은 아니다. 6개월 중 5개월에서 음의 관계를 관측했다.
평가 11월에도 상관은 −0.723이지만 후행 평균은 **−1.1941%**였다(결손56행 제외한 날짜별 평균).
따라서 ‘하락 후 반등 관계가 완전히 뒤집혔다’가 아니라 **관계의 방향이 유지돼도
절대 수익 수준과 종목 선택을 틀릴 수 있었다**가 정확하다. 원모델은 시장 공통 회귀와
개별 종목 선정, 절대 수익 크기를 한 식에 맡겼다.

## 이번 후보: 보정값이 아니라 학습 목적을 변경

같은 학습 자료에서 날짜별로 `X`와 `y`의 평균을 각각 뺀 뒤 종목 간 차이에 Ridge를
적합했다. 예측도 그날 전체 적격 입력 평균을 빼서 계산한다. 예측일의 결과는 읽지 않는다.
공통 기대수익은 학습일 동일가중 평균 **+0.255188%**로 고정한다. α·특성·clip·학습기간
탐색 없이 한 번만 학습했다.

정책은 #813의 정수 수량·보유/신규 구분·비용·5일 간격·5위상·T+2를 그대로 쓴다.
기존 고정 보정 `b=0.00456177185085543`도 바꾸지 않았다. 이 b가 새 모델에 최적이라는
뜻은 아니다. 이번 판정은 **새 모델 + 고정한 기존 정책**에 한정한다. 별도 재보정이나
문턱 인하를 뒤따라 실행하지 않았다.

새 후보는 **매수 0건·주식 노출 0**이다. 정책 23일 새 모델의 보정 전 예측 최댓값이 +2.005946%로,

정수화 오류가 아니라 기대수익이 기존 문턱에 못 미친 결과다. 실제 정수 수량에는
하방위험과 주당 비용까지 적용되므로 위 경계를 넘는 것만으로 매수가 보장되지는 않는다.

새 후보의 사전 위험예산도 0이어서 위험상한을 맞춘 Ridge·시총6 대조 역시 현금이었다.
위험 사용률은 **null/비교 불충분**이지 100%가 아니다. 현금과 동률이고 기존 부모의
평균을 모두 밑도는 반례가 있어 최종 **기각**이다. 전액 예산 시총6 기준도 기본 +1.3844%였다.
계좌 위험이 다른 전액 예산 대조의 숫자만으로 모형의 우열을 단정하지 않는다.

**같은 평가기간에서 계수/보정/문턱을 다시 돌리지 않는다.** 다음은 현재 학습기간 내부를
시간순으로 나눠, 이 14특성이 단순 가격 모멘텀보다 종목 간 차이를 예측하는지 확인할
검증 계약을 정하는 일이다. 목표는 ‘보수적으로 만들어 현금을 늘리는 것’이 아니라
반복 구간 밖에서도 남는 선정 정보를 찾는 것이다. 이번 결과만으로 새 후보를 자동 채택하지 않는다.
