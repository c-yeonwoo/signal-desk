# 국내 재무 카드–보존 원문 대조

작성: 2026-10-03 · 상태: 검사 코드/합성 테스트, **운영 표본 대기**

관리자 › 운영 상태 › 상세 데이터 진단의 `국내 재무 카드·보존 원문 대조` 버튼은 외부 사이트에 접속하지 않는다. 보존된 DART API 응답에서 법인코드를 정렬해 앞의 2개를 **카드 결과를 보기 전에** 고른다. 각 법인의 같은 보고서·연도·연결 기준에서 화면 카드의 매출액·영업이익·영업현금흐름·재고자산을 원문 `thstrm_amount`와 대조한다. 계정 ID, 재무제표 구분, 통화, 접수번호, 전년/당년 금액, 증감률, DART 원문 링크가 모두 맞을 때만 `일치`다. 한 항목이라도 모호하거나 보존 해시가 깨지면 기권/오류로 표시하며 성공으로 세지 않는다.

이 검사는 **저장된 API 응답과 서비스 계산의 정합성**이다. DART 웹사이트 공시 원문의 진위·수정 여부, 실제 공개시각, 종목 수익률을 증명하지 않는다. 두 실측 카드가 모두 일치해도 운영자가 각 접수번호의 공식 원문을 열어 금액·단위·보고기간을 확인하고, 배포 이후 보존본이 남는지 확인해야 데이터 확장 4단계의 원문 대조 관문을 완료로 판정한다. 합성 테스트의 숫자는 운영 증거가 아니다.
