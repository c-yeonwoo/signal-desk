# Railway 키로 과거 SIP 호가 읽기

키는 운영 서버 환경변수 `APCA_API_KEY_ID`·`APCA_API_SECRET_KEY`에만 둔다. 관리자 API는 설정 여부만 알려 주며 키·토큰·계좌를 응답하지 않는다. 로컬 `.env`로 운영 비밀을 옮기지 않는다.

`GET /api/admin/research/alpaca-quotes`는 설정 여부를 확인한다. `symbol/start/end`를 지정하면 고정 패널 AAPL/MSFT/GOOGL/AMZN/META(이전명 FB)/NVDA/JPM/XOM/SPY, 2022~2025년, 5분 이하 구간의 SIP 호가만 조회한다. 최초에는 5초로 제한했으나 희소 구간의 반복 요청을 줄이기 위해 조회 시간 범위만 넓혔다. 1,000행·512,000바이트·15초 응답 상한은 유지한다. [Alpaca 역사 호가 명세](https://docs.alpaca.markets/us/reference/stockquotesingle-1)의 `feed=sip`, `currency=USD`, 과거 `asof`, 오름차순을 명시한다. IEX로 조용히 대체하지 않는다.

한 번에 최대 1,000개·512,000바이트·15초, 관리자 전체 초당 한 구간으로 제한한다. 외부 재지정 URL로 인증을 전달하지 않는다. HTTP 실패와 빈 응답·부분 페이지를 구별하고, 성공 원문의 SHA·바이트·base64와 요청 시작/응답 관측 시각을 함께 반환한다. 실패 본문이나 인증값이 섞인 성공 본문은 내보내지 않는다. 원문은 로컬 연구 ZIP에 보존하며 운영 DB/볼륨에는 대량 호가를 쌓지 않는다.

이는 [발표 직후 진입 원천 검사](EARNINGS-FAST-ENTRY-2026-10-17.md)의 입력 확보 경로다. 과거 호가 원문에 있는 2023년 시장 시각과 지금 요청한 관측 시각은 다르다. 성공 자체가 2023년 당시 시스템의 정보 도착 시각이나 실제 체결을 인증하지 않는다. 운영 시그널·가중치·주문·새 유료 구독은 건드리지 않는다.

첫 접근 검사는 사전에 지정한 AAPL 2023-02-03 장초반과 2023-02-02 시간외의 5초 구간이다. 이 검사에서는 수익률을 계산하지 않는다. 이후 2022 개발/2023 확인 사건의 원문 공개 시각·EPS 기준·전체 표본과 평가 계획을 동결한 뒤 가격을 모은다. 이미 본 2024/2025 결과를 독립 확인으로 재사용하지 않는다.

운영 키 반영과 실제 SIP 원문은 10-17 확인했다. 사전 지정 AAPL 장초반 5초 821행·92,501바이트, 시간외 5초 281행·31,739바이트가 HTTP 200으로 반환됐다. 각각 SHA `eb95cf20de3ecbe4bff29855a0e259f19c32c9c1d0f9d0412ebe682a54bacc69`·`96d24df39a5edb68af1cb97056658305dc16f2d95d4690c2aa7622b840680a62`다. 키·주문은 내보내거나 호출하지 않았다. 이는 접근 증거이지 수익 검증은 아니다.

`GET /api/admin/research/alpaca-news?symbol=…&session=…`는 같은 키로 고정 회사의 **2022/2023 하루 기사**만 읽는다. [공식 뉴스 명세](https://docs.alpaca.markets/us/reference/news-3)의 50행·오름차순·본문 제외와 페이지 토큰을 사용한다. 원문의 `created_at`과 `updated_at`을 함께 보존하며, 수정된 기사를 최초 공개 당시 읽을 수 있었다고 가정하지 않는다. 뉴스와 호가는 하나의 초당 제한을 공유한다. 운영 신호나 주문에는 연결하지 않는다. 다종목 백테스트는 후속 평가 전이며 **통합 진행률 40/100 유지**.
