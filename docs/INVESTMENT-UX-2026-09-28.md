# 투자 관리: 쉬운 해설과 손실 재점검

## 목적과 범위

`paper trading`은 모의투자를 뜻하는 올바른 용어지만, 개인 포트폴리오와 실계좌까지
포함한 상위 메뉴명으로는 부정확하다. 상위 메뉴를 **투자 관리**, 가상 장부를
**봇 모의투자**로 구분한다. 기존 해시 경로·API·장부는 유지한다.

첫 화면은 손익 분해 → 초기자금까지 필요한 상승률 → 다음 점검 계획 → 성향 비교 순서다.
개인 분석은 원본 guidance의 유형·우선순위를 보존하고 쉬운 이유와 행동 설명을 붙인다.
처음에는 최대 세 항목을 보여주며 나머지 항목·배분·매매량·후보·감사 근거는 펼쳐 본다.
새 LLM 호출이나 토큰 비용은 없다. 정량 엔진·자동 주문·위험 한도는 변경하지 않는다.

## 손익과 회복 거리의 정의

- 전체 손익 = 현재 총평가금액 − 고정 초기자금
- 보유 손익 = API의 unrealized_pnl 또는 pnl
- 확정 손익 = 전체 손익 − 보유 손익 (입출금 없는 참조 장부에만 적용)
- 초기자금 미달 시 필요한 상승률 = (초기자금 / 현재 총평가금액 − 1) × 100
- 현재 총평가금액이 0 이하이거나 초기자금이 없으면 회복률을 계산하지 않는다.
- 구성 손익이 없으면 손실 위치 판단을 보류한다. 비용은 손익에서 재차 차감하지 않는다.
- 비용 이력의 기록 건수/전체 건수를 표시한다. 미기록 비용을 0으로 간주하지 않는다.

회복률은 예측·회복 기한·목표 매수량이 아니다. 개인 계좌에 입출금 보정 없이 재사용하면 안 된다.
평가액은 모의 장부의 가격 기준이며, 증권사 실시간 잔고나 체결 가능 가격을 뜻하지 않는다.

## 재점검 계획

확정 손실이 더 크면 반복 진입·청산과 거래비용을 먼저 조사하고, 보유 손실이 더 크면
현재 비중·동반 하락 위험을 우선 확인한다. 수익 상태에는 성과 유지 점검을 표시한다.
자료 부족은 장부 확인 단계만 제공한다. 보유가 없으면 회복 목적의 강제 진입을 제안하지 않는다.

개선 실험 후보는 재진입 지연·거래 축소 또는 비중 축소다. 기존 정책과 동일 기간·비용 조건에서
비교하기 전에는 채택하지 않는다. 이 화면은 검토 계획을 생성할 뿐 실험을 실행하거나
봇 설정을 자동 변경하는 기능이 아니다. 다음 거래일 마감 후 확인할 항목을 안내한다.

손익의 위치를 설명하는 것과 인과적 원인 분해는 다르다. 공격형의 큰 투자 비중은
손실 증폭 요인이 될 수 있지만, 실제 성향 차이는 진입·청산 시점과 종목 구성도 달라
이 화면만으로 그 기여도를 단정하지 않는다. 같은 기간의 시장 기준선이 없으면
‘시장 때문에 손실’이라고 설명하지 않는다. 누적 일수가 늘어도 자동으로 전략 우위를 인정하지 않는다.

## 후속 정량 검증

손실 회복을 위한 정책 변경은 별도 검증이 필요하다.

1. 전체 체결의 FIFO 왕복거래 재생과 장부 합계 일치 확인. 과거 가격·비용 결손 분리.
2. 전략 버전별 손익·종목별 기여·청산 후 재진입·회전 비용 분해. 최근 20건으로 전체 원인을 일반화하지 않기.
3. 동일 시점 후보와 가용 정보로 기존 정책 대비 재진입 지연/비중 축소를 비교.
4. 비용 후 수익과 최대 손실을 함께 평가하고 전진 관측 후 채택 여부 판단.

## 검증

숫자 부호·원금 회복 산식·결측/0 구분·KRW/USD·HTML 이스케이프·비용 중복 차감 방지,
국내/해외·성향 전환 시 늦은 응답 무시, 상세 펼침, 데스크톱/모바일 가로 넘침을 확인한다.
미리보기는 합성 자료만 사용하며 운영 계좌나 투자 한도를 변경하지 않는다.
