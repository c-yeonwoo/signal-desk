# 하루 시장 한눈에 — 데이터·모델·화면 계약

2026-10-04. 이 카드는 **시장 이해용 읽기 화면**이며 새 매매 전략이 아니다. 등록 헤드라인, 팩터 가중치, 봇·실주문 판단을 바꾸지 않는다.

## 첫 구현

`/api/market-brief?market=kr|us` 한 응답에 국내·해외를 **각각** 담는다. 완료된 거래소 세션을 기대일로 정하고 저장된 종가의 주된 날짜와 비교한다. 주된 날짜가 다르면 시장 상태와 매수 건수를 감춘다. 날짜가 맞는 종목만 최근 60개 종가 평균 상회 비율·20개 종가 간 수익률 평균에 넣고, 빠진 종목 수를 밝힌다. **중간 봉 구멍은 보간하지 않으므로 20개 관측을 언제나 20거래일이라고 부르지 않는다.** 일부 종목만 최신이면 시장 흐름은 표본을 밝힌 채 보여주되 **전체 매수 판정 건수는 보류**한다. 이는 기존 `regime.classify`를 읽기 전용으로 재사용한 **유니버스 근사**이며 지수 자체나 내일 상승 확률이 아니다. 미국은 같은 원시 관측값만 보여주고 국내 `강세/약세` 분류를 미국 시장 이름으로 복제하지 않는다. 어떤 카드도 매매 게이트에 연결하지 않는다.

첫 화면은 `시장/종가 날짜 → 종목 흐름 → 확인 가능한 이유 2~3개 → 현재 매수 판정 수/별도 계산시각 → 모르는 점` 순서다. 수급과 나스닥은 해당 완료일 또는 직전 세션의 관측 날짜가 확인될 때만 이유에 들어간다. 경제 지표·미국 산업 통계·국내 체온계는 한 카드의 `수치·원문 근거 보기`에 둔다. 미국 시황 해설은 요약 생성일이 아니라 **원문 발행 최신일**이 확인되고 신선할 때만 그 안에 보인다. 선택 종목의 점수나 주문에 이 카드의 문장은 전달하지 않는다.

## LLM과 API 키

첫 배포의 시장 상태·숫자·문구는 결정론적이다. **페이지 조회 시 LLM·이미지 생성 호출 0회**, 별도 환경변수 0개다. 기존 거시 KB 해설은 이미 `llm.NARRATIVE_MODEL`인 `claude-sonnet-5`와 서버의 `ANTHROPIC_API_KEY`를 쓰며, `LLM_DAILY_BUDGET_USD`/`LLM_MONTHLY_BUDGET_USD`의 중앙 예산 게이트와 용도별 사용량 기록을 통과한다. 새 `OPENAI_API_KEY`나 `GEMINI_API_KEY`를 요청하지 않는다. 브라우저로 키를 내리지 않는다.

짧은 문장 품질을 더 높일 필요가 **운영 비교에서 확인되면**, 같은 Sonnet 5로 시장·완료 세션당 최대 1회 비동기 생성해 저장한다. 출력은 사실 ID를 참조하는 짧은 문장만 허용하고, 날짜·수치·종목·매수/매도 표현은 모델 생성문에서 금지한다. 검증 실패, 키 없음, 예산 초과, 타임아웃이면 현재의 규칙 문장을 그대로 쓴다. 사용자 조회는 절대 모델을 호출하지 않는다. Sonnet 5 가격은 [Anthropic 공식 모델 문서](https://platform.claude.com/docs/en/models/sonnet-5/overview) 기준 입력 $2/백만 토큰, 출력 $10/백만 토큰이다. 이는 **향후 선택지**이지 이번 배포의 새 호출 비용이 아니다. 품질 평가는 사람이 동일 스냅샷의 규칙 문장과 LLM 문장을 블라인드로 비교하고, 수치·시점 오류 0건을 필수 조건으로 한다.

이미지 생성 모델은 숫자·한글·원문 출처가 있는 금융 카드를 직접 그리는 데 쓰지 않는다. 이미지가 필요하면 **동일 JSON에서 HTML/SVG를 결정론적으로 그리고 PNG로 내보내** 앱·텔레그램에 재사용한다. 장식용 배경을 별도 생성할 수는 있지만 데이터-bearing 텍스트와 분리한다. [OpenAI 이미지 생성 문서](https://developers.openai.com/api/docs/guides/image-generation)는 정확한 글자 배치·구조화된 구성의 한계를 명시한다.

## 다음 관문

1. 운영에서 국내·해외의 기대 거래일, 실제 종가 날짜, 제외 종목 수, 현재 판정 시각을 확인한다. 시세가 늦으면 카드가 실제로 기권하는지 확인한다.
2. 같은 JSON을 SVG/PNG로 내보내는 공유 이미지와 접근 가능한 텍스트 대체를 붙인다. 그림만 남기지 않는다.
3. 사용자 이해도 평가 후에만 선택적 LLM 문장 실험을 연다. 좋아 보인다는 인상이나 수익률로 카드 문장 모델을 승격하지 않는다.

이 작업은 Signal Desk 2.0 데이터 확장 4단계의 DART·연준·SEC 원문 대조, 초보자 평가 완료 증거가 아니므로 그 진행률을 올리지 않는다.
