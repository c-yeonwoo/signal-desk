# 화면 문장 원칙

시그널·기업 소식·시장 해설을 쓸 때의 공통 기준이다. 설명만 만드는 생성 경로에는 `signal_desk.copy_style.PLAIN_KOREAN`을 프롬프트에 포함하고, 화면에서 긴 원문을 접을 때는 `readableText()`를 쓴다. **원문과 수치, 판정은 요약 때문에 바꾸지 않는다.** 후보를 고르거나 악재를 차단하는 판단 프롬프트는 문체를 이유로 수정하지 않는다.

1. 결론부터 한 문장으로 쓴다. 이어서 가장 중요한 근거 한두 개만 붙인다. 확인되지 않은 원인은 추측하지 않는다.
2. 한 문장에는 사실 하나를 담고, 평이한 존댓말을 쓴다. `쉽게 말하면`, `종합적으로 볼 때`, `시사합니다`, `~로 판단됩니다` 같은 상투어를 빼도 뜻이 유지되면 뺀다.
3. 사용자 화면에서는 `KB` → `기업 소식`, `팩터` → `점수 구성`, `Decision veto` → `확인된 악재로 새 매수 차단`처럼 *무엇을 뜻하는지* 쓴다. 관리자 진단의 원래 코드값은 추적을 위해 남길 수 있다.
4. 점수로 만든 판정, 점수 밖의 참고 자료, 봇 계좌의 매매 행동을 구분한다. 뉴스 분위기를 실제 시그널 점수나 계좌 매매 지시로 표현하지 않는다.
5. 모바일에서도 핵심 문장은 기본 글자 15px 이상을 목표로 하고, 긴 근거는 `전체 설명과 근거`처럼 사용자가 펼쳐 읽게 한다. 원문을 숨기거나 삭제하지 않는다.
6. `강력매수`는 상대 순위 판정이지 수익 보장이나 개인 계좌의 추가 매수 지시가 아니다. 적중률·백테스트·연구 결과에는 표본과 성격을 함께 적는다.

새 카드를 만들거나 문장을 고칠 때에는 **첫 줄만 읽어도 무엇이 확인됐는지 알 수 있는가**, **근거가 없는데 이유를 단정하지 않았는가**, **전문용어를 몰라도 이해되는가**를 확인한다. 수치를 쉽게 바꾸는 과정에서 `목표 8%±25%` 같은 상대 밴드를 `유지 범위 6~10%`처럼 실제 구간으로 풀어 쓸 때도 계산식과 원래 제약은 유지한다.
