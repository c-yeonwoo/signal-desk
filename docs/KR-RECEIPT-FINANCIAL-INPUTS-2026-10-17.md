# 국내 과거 재무 입력과 선정 비교

**재무 원천 확보와 날짜별 차단을 구현했다. 재무를 추가하면 선정이 크게 달라지지만 성과가 일관되게 좋아지지는 않았다.** 기본·저평가·퀄리티를 더한 개발 민감도이며 수급·공매도·정성 사건까지 복원한 실제 8팩터 성적은 아니다. 운영 엔진·가중치·매매 규칙은 유지한다.

## 확보한 데이터

기존 7창에서 계산됐던 **256종목 전체 × FY2022~2025 = 1,024종목·연도**를 고정했다. FY2022는 전년 대비 퀄리티용이다. [DART 다중회사 주요계정](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2019017)으로 회사 매핑 1건·재무 묶음 12건, **13개 논리 요청**의 원문을 약 4.76MB ZIP으로 보존했다. 재시도가 있으면 실제 HTTP 횟수는 더 클 수 있다. Railway 운영 캐시에는 넣지 않았다.

958건은 접수번호·회사·연도·원화·연결/별도 기준을 구분했다. 그중 875건은 순이익·자본·ROE·부채비율·매출성장을 모두 계산했다. 계정 없음 57건, 비12월 결산/기간 미확인 4건, 접수번호·통화 등 불명확 5건은 보존하고 제외 사유를 남겼다. 출처 없는 기존 199종목 연간 캐시는 사용하지 않았다.

연결 수치가 없다고 별도 수치로 메우지 않고, 동일한 순이익 중복 행은 값·기간·계정이 모두 같을 때만 합친다. **조회 사업연도가 과거여도 반환된 접수번호가 판단일 이후면 사용하지 않는다.** 4월 1일이라는 연도 전환 가정만으로는 나중 정정본의 소급 사용을 막을 수 없다.

삼성전자 `20260310002820`, SK하이닉스 `20260317000635`는 [접수번호별 XBRL 원본](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS002&apiId=2019019)도 받았다. 회사·연결 전체·원화·당기/전기 기간을 대조하니 위 5개 값이 API와 일치했다. **2개 원문 대조**이지 958건 전체의 정정 이력 인증은 아니다. 해시와 결과는 [기계 판독 요약](kr-receipt-financial-summary-2026-10-17.json)에 남겼다. 초기 ZIP의 파서 집계는 보존하고 재검수 시 원문에서 다시 계산한다.

## 같은 종목군에서 달라진 것

**293판단일의 당시 KOSPI 시총 상위 200 보통주**를 유지했다. 두 경로에 같은 연속 253개 종가를 넣고 추가 경로만 해당일 시가총액과 접수일로 제한한 연간 재무를 결합했다. 연간 재무 전환은 기존 4월 규약에 실제 접수일 다음 세션 가정을 더했다. 당시 실제 캐시·분기 업데이트·정정 전 버전을 완전히 복원한 것은 아니다. 새 가중치·분위·손절값은 탐색하지 않았다.

## 판단과 다음 작업

**접수번호 기반 연구 입력 경로는 채택하고 새 매매 정책은 채택하지 않는다.** 수급·공매도, 당시 섹터 분류·정성 사건, 기업행사 총수익과 실제 체결은 별도 미완료다. 보호 구간 가격 결과는 사용하지 않았다.

초기 단계 전체 테스트는 2,562개가 통과했다. 아래 후속에서 **나중 정정본 때문에 빠진 20개 회사의 원본 복원·재비교**를 진행했다. 운영 가중치·문턱과 통합 **40/100**은 유지한다.

재현: `.venv/bin/python -m scripts.measure.kr_financial_input_sources --output data/research/<새 원천>.zip`, 이후 `.venv/bin/python -m scripts.measure.kr_receipt_financial_lab --source data/research/<원천>.zip --output data/research/<새 결과>.json`. 수집에는 기존 동결 국내 장부와 DART 키가 필요하다. 보존 원천으로 재생할 때는 네트워크 요청이 없으며 원문·결과를 덮어쓰지 않는다.

## 후속: 20개 회사의 원본·정정 버전 복원

기존 원천에서 **FY2025 반환 접수일이 2026-06-01 이후이며, 동결한 3월 목록에 같은 회사·회계연도 사업보고서가 있는 20개 회사**를 선정했다. 새 가격 결과를 보고 대상을 고르지 않았다. 3월 26접수에 4~7월 목록 988건 중 해당 회사의 후속 보고서를 연결해 **45접수**를 보존했다. 새 목록 11요청·원본 45 HTTP 요청, 총 56논리 요청이며 ZIP은 **52.20MB**다. 로컬 연구 저장소에만 두었다.

**20개 회사 모두에서 원본 재무를 읽었고, 접수 버전 단위로는 43/45건**이다. 실제 XBRL이 20~22MB인 보고서도 있어 읽기 상한은 32MB로 제한했다. 8버전에는 일반 매출성장 항목이 없어 순이익·자본 등 확인된 값만 사용하며 보험/은행 계정을 임의로 매출로 바꾸지 않는다. 같은 접수번호의 현 API 자료가 있는 11건은 공통 재무 값이 모두 일치했다. 고려아연의 3월 원본 자본과 8월 반환본 자본은 실제로 달라, 나중 수치를 과거에 소급하는 방식은 여전히 허용하지 않는다.

DL이앤씨 `375500/20260317000901`, 엘앤에프 `066970/20260423000699` 첨부정정은 DART가 `014`(파일 없음)를 반환했다. 첨부정정이라는 제목만으로 재무가 같다고 간주하지 않는다. 같은 날 성공 원본과 실패 정정이 겹치면 순서를 추정하지 않고 사용을 보류하며, 이후 다른 날의 명확한 버전이 있으면 그 다음 세션부터 다시 사용한다. 모든 버전은 공시 당일이 아니라 **다음 정규 세션부터 사용한다는 가정**이다. 당시 공급자 도착 시각이나 운영 캐시 인증은 아니다.

같은 293일을 다시 계산하니 가격 전용 대조의 모든 날짜별 결과와 앞선 다섯 창은 그대로였고, **재무 경로의 매수 집합은 29일 바뀌었다.** 결과가 좋은 날짜만 남겨 전체 수익률로 발표하지 않는다.

| --- | ---: | --- | ---: | ---: |
| 2026 4–5월 | 24→9 / 40일 | 171~178→185~192 | 16일 | −3.77%→−4.11% |

위 평균은 **양쪽에서 매수와 가격이 모두 있는 일부 날짜의 중첩 h5 라벨**이며 계좌 수익률·독립 검증·전체 창 성적이 아니다. 여전히 매수 없는 날이 있어 두 창의 전체 평균은 null이다. **자료 복원으로 공석은 줄었지만 선정의 수익 우위는 확인되지 않았다.** 따라서 연구용 원본 버전 경로만 채택하고 매매 정책 승격은 하지 않는다. 과거 API의 늦은 접수번호가 연구 커버리지를 왜곡한 부분과 엔진의 선정 능력을 구분한 것이 성과다.

다음 핵심으로 정한 29판단일의 팩터별 선정 이유와 이후 손실 분해는 아래 후속에서 완료했다. 새 정책을 제안하면 이 개발 구간에서의 설명과 별도 미사용 표본에서의 채택 판단을 분리한다. 일봉 선정 비교를 발표 직후·장중 진입 타이밍의 검증으로 말하지 않는다. 수급·공매도·정성 사건·기업행사와 독립 성능 관문은 남아 있다.

재현: `.venv/bin/python -m scripts.measure.kr_original_financial_sources --output data/research/<새 원본 버전>.zip`; 이후 기존 실행기에 `--versions data/research/<원본 버전>.zip`을 추가한다. 최종 결과는 `kr-original-financial-sensitivity-2026-10-17-v3.json`이며 원천·결과·실행 코드 해시는 같은 [기계 판독 요약](kr-receipt-financial-summary-2026-10-17.json)의 `original_recovery`에 있다. 원문 재정규화 후 두 실행의 날짜별 결과 일치와 가격 전용 대조 불변을 확인했고, 전체 테스트 **2,565개**가 통과했다.

## 후속: 선정 변경 29일의 원인 분해

통합 로드맵 **C3/R2**다. 추가 API·LLM·운영 주문 없이 4~6월 **61판단일 전체(변경29·불변32)**를 재생했다. 당시 후보 12,200자리 중 연속 종가로 계산된 **11,974종목일**을 전후 비교하고, 계산 안 된 226자리는 분모에 남겼다. 61일의 기존·복원 후 매수 목록과 h5 집계가 동결 결과와 모두 일치했다. 기술 원값 대신 실제 유효 기여의 합을 점수와 대조하며, 기여가 같은 팩터는 공동 1위로 기록한다.
