# 사건 정보의 추가 선정력 점검

2025 가격·거래량 돌파 후보는 기각했다. 다음 점검은 이미 있는 사건 자료와 동일 분봉 구간을
연결할 수 있는지, 사건 정보가 기존 가격 전용 후보에서 의미 있는 구분을 주는지다.
운영 설정·등록 가중치·실주문을 바꾸지 않는다.

## 수집·계산 전 범위 고정

- 보존된 EPS 원천의 **날짜·회사·회계기간만** 읽어 2025-01-01~06-26의 8회사·16발표를 고정한다.
  현재 제공자 EPS 예상값이나 pre/post-market 라벨은 선정/진입 입력에 쓰지 않는다.
- 보존 기사 원문은 2020~2023에만 있어 2025와 겹치지 않는다. 기존 Alpaca 권한으로 고정
  16발표의 발표일 뉴스와 GOOG 별칭2일을 보충한다. 최대72요청·일자/심볼당4페이지,
  50건/페이지이며 실패는 그대로 보존한다. 유료 구매·LLM 호출은 없다.
- 기존 `earnings_guidance_validation.input_events`를 재사용한다. 직접 실적 기사 최초 확인
  뒤10분 안 EPS 상회5%·총매출 예상 상회·알려진 하향 전망 없음이라는 **기존 규칙**을 그대로 쓴다.
  전망 없음은 미확인으로 남긴다. 이 필터의 효과를 확인하기 위해 이번 구간을 새로 최적화하지 않는다.
- `max(created_at, updated_at)`에 근거한 확인 시각을 사용한다. 해당 시각까지 완료된 첫
  정규장5분 뒤에만 사건 필터를 적용한다. 발표일 뉴스만 쓰므로 다음날 새 기사·콜까지 모두
  파악했다고 하지 않는다. 역사 API 도착 시각·최초 버전 인증도 아니다.
- 같은120세션·8종목·위험 한도·확인 진입·60분 보유·편도12bp 가정 비용에 사건 필터만 추가한다.
  이미 확보한 진입/청산 호가를 재사용한다. 가격 전용 및 거래대금 기준의 보존 결과를 대조한다.
  결손 회사/페이지는 0거래로 바꾸지 않는다.
- **2025 가격 결과를 이미 본 뒤의 진단**이다. 새 독립 확인·통계적 수익성 채택으로 세지 않는다.
  선택 가능한 사건이 거의 없거나 수익이 악화되면 이 결합을 종료한다. 수익이 나더라도 특정
  사건·낮아진 노출의 영향을 따로 밝히고 운영을 자동 승격하지 않는다.

원천과 결과는 로컬 `data/research`에만 보존한다. 원천·코드·계획 해시로 재현한다.
통합 로드맵 **40/100 유지**.

## 수익 계산 전 원천 결함 확인

18요청 모두 정상·페이지 완결이다. 기존 파서는8발표를 `direct_report_missing`으로 처리했지만,
원문에는 회계연도/GAAP 표기나 `Meta Platforms`라는 회사명 형태로 직접 실적 기사가 있었다.
이 형식만 새 진단에서 정규화한다. 수치·수정 시각·`May Not Compare` 문구는 보존하며, GAAP
라벨도 산출물에 명시한다. 기존2020/2021 파서와 확정 결과는 바꾸지 않는다. 근거 raw SHA와
원문 제목 해시·파생 제목을 함께 남긴다. 추가 근거 없이 근사 전망(`~`)을 정확한 전망으로 바꾸지 않는다.

보존된 대조 결과의 분봉·호가1,360개 해시와 새 경로가 읽는 파일 전체를 정확히 대조한다.
제공자 수정본·추가 파일을 섞으면 비교를 중단하며 해당 해시 맵의 지문을 새 결과에 남긴다.

거래0건의 이유를 확인한 뒤, 고정16발표 **전체**의 첫5분 종료~65분 종료 가격 변화를 진단한다.
같은 날짜·같은 시각의 SPY도 보충해 시장과의 차이를 보되, 이는 사후 원인 점검이며
새 체결 백테스트/독립 확인/매수 규칙으로 쓰지 않는다. SPY는 중복 날짜를 합친 일자별1요청만
읽는다. 회사·시간 지평·좋은 사건만 남기는 변경은 하지 않는다. 각 분봉 원문을 별도 보존한다.

## 결과 · 이번 결합 종료

형식 보완 뒤16발표 모두 `ready`, EPS 조건 통과는9건, 매출·알려진 전망까지 통과한 사건은6건이다.
**사건 필터+기존 확인 돌파의 실제 거래는0건**이며, 120세션 계좌는 현금0%로 완결했다.
이는 매매 수익성 개선이나 정확도 향상으로 세지 않는다. 보존된 가격 전용 후보는 같은
앞/뒤60일에11/11건을 거래해−0.31195%/−0.49302%였고, 거래대금 기준은30/19건·
−1.19294%/−1.22725%였다. 서로 다른 실제 노출을 유지한 결과다.

실제 수수료를 적용한 가상 체결 수익이 아니다. 고정16발표 모두에 같은 지평을 적용했다.
조건 통과6건은 평균−0.84753%, 해당 SPY 평균+0.04682%, 가격 차이−0.89435%p다.
그 외10건은 평균−0.54428%·SPY 대비−0.58052%p, 전체16건은 평균−0.65800%·
SPY 대비−0.69821%p다. 같은 날짜의 여러 회사가 있어16개의 독립 관측이라고 하지 않으며,
종목 베타를 조정한 알파나 날짜가 다른 두 그룹의 인과 효과로 해석하지 않는다.

따라서 **호재를 읽은 뒤 기존 돌파 조건에 단순히 AND로 붙이는 방안은 채택하지 않는다.**
제한을 풀어야 수익이 좋아진다는 근거도 없다. 이 표본에서는 호재 후에도 개장 이후 매수세가
이어지지 않은 사건들이 있었다. 발표 시점의 호재와 다음 정규장 한 시간의 매매 우위를 구분한다.
이 결과로 쇼트 전략을 만들거나 반대편 수익을 소급 계산하지 않는다.

### 실제로 보완된 것

- 연구 입력의 회사명·회계연도·GAAP 형식 누락을 고쳤다. 원문8건의 누락은 현재 코드로
  재현하고 보완 후16/16 입력을 확인했다. EPS 비교 불가 기사·부분 매출·미확인 전망을
  긍정 근거로 바꾸지 않는다. 새 진단에서만 정규화하므로 과거 확정 연구 결과는 보존된다.
- Alpha Vantage 원천에서 AMZN 2025-02-06의 `reportTime`은 `pre-market`이지만 보존한
  직접 실적 기사의 공개는21:01:36 UTC(장후)다. 이 범주값을 시각 대신 썼다면 진입일이
  잘못됐을 사례다. 새 진단은 실제 기사 시각을 사용해02-07 정규장에만 연결했다.
- 새 경로의 분봉·호가를 대조 결과의1,360개 원문 해시에 묶었다. 같은 날짜의 수정본을
  새 경로에만 섞으면 비교를 거부한다. 이는 수익성 개선이 아닌 비교 오류 방지다.

운영 시그널·주문·LLM 판단을 바꾸는 코드는 없다. 이번 미채택 후보를 앱에 새 필터로 추가하지
않는다. 수익성 개선 미입증·통합 로드맵 **40/100 유지**.
