# 사건 정보의 추가 선정력 점검

2025 가격·거래량 돌파 후보는 기각했다. 다음 점검은 이미 있는 사건 자료와 동일 분봉 구간을
연결할 수 있는지, 사건 정보가 기존 가격 전용 후보에서 의미 있는 구분을 주는지다.
운영 설정·등록 가중치·실주문을 바꾸지 않는다.

## 수집·계산 전 범위 고정

- 보존된 EPS 원천의 **날짜·회사·회계기간만** 읽어 2025-01-01~06-26의 8회사·16발표를 고정한다.
  현재 제공자 EPS 예상값이나 pre/post-market 라벨은 선정/진입 입력에 쓰지 않는다.
- 보존 기사 원문은 2020~2023에만 있어 2025와 겹치지 않는다. 기존 Alpaca 권한으로 고정
  16발표의 발표일 뉴스와 GOOG 별칭2일을 보충한다. 최대72요청·일자/심볼당4페이지,
  50건/페이지이며 실패는 그대로 보존한다. 유료 구매·LLM 호출은 없다.
- 기존 `earnings_guidance_validation.input_events`를 재사용한다. 직접 실적 기사 최초 확인
  뒤10분 안 EPS 상회5%·총매출 예상 상회·알려진 하향 전망 없음이라는 **기존 규칙**을 그대로 쓴다.
  전망 없음은 미확인으로 남긴다. 이 필터의 효과를 확인하기 위해 이번 구간을 새로 최적화하지 않는다.
- `max(created_at, updated_at)`에 근거한 확인 시각을 사용한다. 해당 시각까지 완료된 첫
  정규장5분 뒤에만 사건 필터를 적용한다. 발표일 뉴스만 쓰므로 다음날 새 기사·콜까지 모두
  파악했다고 하지 않는다. 역사 API 도착 시각·최초 버전 인증도 아니다.
- 같은120세션·8종목·위험 한도·확인 진입·60분 보유·편도12bp 가정 비용에 사건 필터만 추가한다.
  이미 확보한 진입/청산 호가를 재사용한다. 가격 전용 및 거래대금 기준의 보존 결과를 대조한다.
  결손 회사/페이지는 0거래로 바꾸지 않는다.
- **2025 가격 결과를 이미 본 뒤의 진단**이다. 새 독립 확인·통계적 수익성 채택으로 세지 않는다.
  선택 가능한 사건이 거의 없거나 수익이 악화되면 이 결합을 종료한다. 수익이 나더라도 특정
  사건·낮아진 노출의 영향을 따로 밝히고 운영을 자동 승격하지 않는다.

원천과 결과는 로컬 `data/research`에만 보존한다. 원천·코드·계획 해시로 재현한다.
통합 로드맵 **40/100 유지**.

## 수익 계산 전 원천 결함 확인

18요청 모두 정상·페이지 완결이다. 기존 파서는8발표를 `direct_report_missing`으로 처리했지만,
원문에는 회계연도/GAAP 표기나 `Meta Platforms`라는 회사명 형태로 직접 실적 기사가 있었다.
이 형식만 새 진단에서 정규화한다. 수치·수정 시각·`May Not Compare` 문구는 보존하며, GAAP
라벨도 산출물에 명시한다. 기존2020/2021 파서와 확정 결과는 바꾸지 않는다. 근거 raw SHA와
원문 제목 해시·파생 제목을 함께 남긴다. 추가 근거 없이 근사 전망(`~`)을 정확한 전망으로 바꾸지 않는다.

보존된 대조 결과의 분봉·호가1,360개 해시와 새 경로가 읽는 파일 전체를 정확히 대조한다.
제공자 수정본·추가 파일을 섞으면 비교를 중단하며 해당 해시 맵의 지문을 새 결과에 남긴다.
