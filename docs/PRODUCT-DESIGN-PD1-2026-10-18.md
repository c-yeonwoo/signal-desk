# SIG-25 · 종목 화면 기준선과 개선 시안

상태: 현재 배포 화면 관찰·기존 피드백 대조·개선안·격리 시안 검수 완료. 실제 운영 UI와 엔진은 바꾸지 않았다. 비교 소스는 main `48d3eefde68ffe3e3a78b4735d5211fbee86c38f`이며 운영 배포 SHA 자체를 확인한 것은 아니다. 소유자 수용과 운영 적용은 다음 SIG-26의 범위다.

## 현재 관찰과 기존 피드백 대조

2026-10-18 19:48 KST 전후, 소유자 로그인 세션의 새 Chrome 탭에서 `/?v=pd1-48d3eef#signal`을 열었다. 국내·해외·관심, 검색 결과 없음과 선택 해제를 확인했다. 데스크톱1440×1000·모바일390×844 CSS px다. 실제 계좌 페이지·주문·설정은 열지 않았다. 관찰은 종목 흐름에 한정한다.

## 실제 남은 우선 문제

1. **휴장 종가 설명 반복:** 국내 KCC 상세의 기준 줄·상단 경고·한 줄 이유·기업 근거 제목 아래·가격 근거 칸이 같은 사실을 반복한다. 가격 기준 한 줄은 유지하되 정보 단위를 합친다.
2. **모바일 표 겹침:**390px에서 종목 코드/점수/자료 비중과 등급이 같은 영역을 침범한다. 선택 상세가 표 안1797px 높이의 drill-row로 들어간다. 긴 경고 문장도 오른쪽에서 잘린다. 수집/판정 결함으로 오인하지 않도록 UI 결함으로 한정한다.
3. **차트와 근거의 순서:**1440px에서 KCC 상단 요약329px·기업 근거384px이며 차트 시작 y≈1128px다. 시장 반응을 보기 전에 같은 설명을 여러 번 지나야 한다. 가격 뒤 간결한 판단 맥락·차트·근거로 배치한다.
4. **목록 비교에 가격이 없음:** 현재 API의 `price/change_pct`는 있으나 기본 시그널순 표에는 점수·비중·섹터·등급이 먼저 나온다. 시안은 가격·변화와 후보 상태를 읽게 하고 계산값은 상세로 옮긴다. 새 추천 순서나 API는 만들지 않는다.
5. **정성 근거 없는 상태의 큰 빈 카드:** 원문이 없는데도 ‘기업 소식 함께 보기’가 큰 영역을 사용한다. 짧고 정확한 미확인 안내를 유지하고, 원문이 있을 때만 그 원문을 읽는 공간을 넓힌다.

원본 화면은 회사 runtime의 `missions/product-design-2026-10-18/pd1/before-*.png`에 비공개 보존한다. 사용자 식별자·관심 목록이 포함될 수 있어 Git에 올리지 않는다. 문서의 수치는 화면 관찰값이며 가격/판정의 정확성이나 수익을 검증한 값이 아니다. 다른 메뉴의 현재 결함이나 Core Web Vitals는 이번에 측정하지 않았다.

## 개선안과 시안 범위

- 데스크톱: 왼쪽 목록·오른쪽 상세는 유지한다. 목록은 종목/가격/변화/후보 상태를 정렬해 겹침을 없앤다. 점수와 계산 자료 비중은 상세 근거로 옮긴다. 검증 상태는 짧은 한 줄에서 계속 확인한다.
- 상세: 이름·가격·기준 시각 → 현재 판정의 범위 → 첫 매수권 뒤 가격 변화 → 가격 흐름 → 좋게 본 점/먼저 확인할 점 → 원문·계산 자료·기록. 기록상 가격 차이를 실제 매입 손익으로 표시하거나, 보유자 판단을 신규 후보 등급에서 새로 도출하지 않는다.
- 모바일: 표 내부에 긴 상세를 삽입하지 않는다. 목록과 상세를 오가고 돌아왔을 때 검색·정렬·관심 상태를 유지하는 시안이다. 실제 서비스의 기존 딥링크와 선택/요청 경합은 PD2 구현에서 별도로 검증한다.
- 종가 확인/갱신 지연/가격 없음/조회 중/조회 실패를 전환해 문구와 가격·등급 표시를 확인한다. 국내/해외/관심·검색·정렬·관심 토글은 시안 메모리 안에서만 동작한다.
- 모든 시안 데이터는 예시다. 실제 공시·기사를 지어내지 않고 원문 없음 상태를 사용한다. 운영 API·계좌·주문·LLM 호출·분석 모델과 연결하지 않는다.

## Direction contract

**THESIS:** 같은 종목의 가격·후보 평가·보유에 대한 질문을 순서대로 읽게 한다. 기존 두 영역 구조 안에서 반복 설명을 줄이고 비교가 가능한 목록을 만든다.

**OWN-WORLD:** 현재 `design-tokens.css`의 밝은 중성 표면과 indigo 액센트를 계승한다. 매수/매도 의미 색은 상태 텍스트에만 쓰며 평면 구분선·16px 본문·명확한 버튼과 포커스를 사용한다. 새 브랜드를 만들지 않는다.

**STORY:** 목록에서 종목을 골라 가격과 판정의 시점을 확인하고, 근거와 빠진 자료를 본 뒤 보유 진단이 필요한지 구별한다.

**FIRST VIEWPORT:**1440px에서 약340px 목록과 나머지 상세,390px에서는 단일 목록/선택 상세다. 상세 첫 화면에 가격·기준 시각·짧은 후보 맥락·가격 흐름이 나타난다. 주 행동은 원문/판정 근거 확인이며 주문 버튼은 없다.

**FORM:** 기존 종목 화면의 한정 개선 시안. 기존 시각 체계와 두 영역 구성을 유지하므로 새 시각 세계 추첨/seed는 적용하지 않는다. HTML/CSS/데이터 차트로 직접 만드는 시안이며 생성 이미지의 대체 렌더가 아니다.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

기존 DESIGN.md의 과거 teal 설명은 현행 CSS와 충돌한다. 시안은 현재 CSS를 따른다. 이 충돌을 새 브랜드 선정이나 문서 전체 덮어쓰기의 근거로 삼지 않는다. 시안 검수와 기존 시각 기준 계승 여부를 마감 기록에 남긴다.

- 최종 캡처: [PC 전체](../.impeccable/review/pd1/desktop.png), [모바일 목록](../.impeccable/review/pd1/mobile-list.png), [모바일 상세](../.impeccable/review/pd1/mobile-detail.png). 모두 예시 데이터가 표시된 브라우저 화면이다. 생성 이미지나 운영 가격 증거가 아니다. [캡처 출처](../.impeccable/review/pd1/captures.json)를 함께 보존한다.
- 실제 브라우저에서 15개 상호작용을 확인했다. 5가지 가격 상태, 모바일 재시도/목록 복귀, 긴 이름, 빈 검색, 해외 통화, 관심 해제/빈 목록, 높은 점수의 관망 유지, 데스크톱 키보드 선택/재시도다. 가격 없음·조회 중·실패는 가격/차트/등급을 숨기고, 지연은 이전 판정임을 표시한다. 가격 없음 안내는 최종 문구로 한 번 더 대조했다. 세부 기록은 비공개 runtime `pd1/interaction-checks.json`이다.
- JS 구문 검사 통과. Impeccable 기계 탐지 결과는 `[]`이며, 전체 접근성/성능 인증을 의미하지 않는다. 이번에 Core Web Vitals나 운영 로딩 속도를 측정한 것은 아니다.
- 독립 마감 리뷰의 판정은 **ship**이다. 발견한 포커스 손실, 모바일 작은 차트 축/입력, 가격 변화 위치, 반복 문구를 한 번에 수정한 뒤 최종 소스와 3개 캡처를 재검토했다. 미해결 수정 목록은 없다. 리뷰어는 직접 브라우저를 실행하지 않았으며 브라우저 조작은 controller의 별도 기록이다.
- 독립 문서 검토에서 현행 중성색/indigo/매수·매도 의미색과 16px/1.6 본문의 계승을 확인했다. 운영은 Pretendard 우선, 시안은 시스템 폰트 우선이며 제목25px·라운드12px도 시안 값이다. 토큰 완전 동일을 주장하지 않는다. 기존 DESIGN.md 정합은 PD5에서 다룬다.
- Impeccable의 범위 고정·실화면 비교·묶음 검수·문서화 원칙을 적용했다. 전용 마감 리뷰/문서화 agent 유형이 제공되지 않아 일반 독립 리뷰어·문서 검토자로 대체했다. 새 브랜드 선정이나 정식 이중 critique를 수행했다고 보고하지 않는다.

## SIG-26 구현 인수 조건

1. 국내/해외/관심·검색·정렬·긴 이름·빈 결과에서 목록과 상세가 일치한다. 모바일 왕복·키보드 포커스·기존 딥링크·늦은 응답에서 선택 상태를 보존한다.
2. 실제 API의 가격·통화·시장별 기준시각과 지연/결측/로딩/오류를 그대로 표시한다. 후보 판정·보유 대응·기록상 가격 차이를 구별한다. 기존 순위·점수·매매 조건을 바꾸지 않는다.
3. PC1440×1000·모바일390×844에서 시안과 운영 구현을 대조하고, 현행 토큰/폰트 적용·독립 리뷰·정확한 PR HEAD CI·배포 SHA·소유자 피드백을 기록한다. 시안의 합성 데이터/하드코딩 정렬/관심 상태를 운영 로직으로 복사하지 않는다.

완료 집계: **PD1 완료1/6(16.7%)**. 운영 목록/상세 구현·배포·소유자 수용은 미완료다. 기존 통합 로드맵은 **40% 유지**한다.
