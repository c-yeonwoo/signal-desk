# 동일 실적 사건의 진입 시점 비교

## 결과 열람 전 고정

기준 main `7163210`(#833). 기존 사건 결과 SHA-256
`8372a7acf31db419d876d1efd16c9c976aa21d634a52354d8cb7c17ae1ba4772`에서
16건 전체의 자료 상태를 보존하고, 기존 적격 6건을 양쪽에 똑같이 배정한다.
새 종목·사건 선정이나 기존 ORB 조건 완화가 아니다. 이미 본 2025년 상반기 자료의
**진입 시점 진단**이며 독립 평가나 운영 성적이 아니다.

- 발표 직후: 기존 기사 생성/수정 중 늦은 시각 + 처리 10분. 실제 최초 공시 시각/당시 API 도착을 인증하지 않는다.
- 첫 정규장: 위 처리 시각 이후 첫 미국 정규장 개장 5분 뒤. 장전 발표는 당일, 장후 발표는 다음 세션이다.
- 양쪽 모두 $10,000 시작, 사건마다 가용 현금 1/6 이하, 정수 주식, 기준 ask +0.3% 지정가 한도.
  기준 호가 관측 1초 이후 최초 정상 ask로 진입, 실제 진입 60분 뒤 최초 정상 bid로 청산.
  정상 조건 R, bid<ask, 양쪽 양수 수량/가격, 수량 한도 적용. 2025년 상반기 raw size ×100은 가정으로 명시한다.
- 매수·매도 각각 12bp(토스 수수료 참고 10bp + 여유 2bp) 가정. 당시 계좌 정산 비용의 인증값이 아니다.
  ask/bid 차이는 이미 체결 가격에 포함되어 별도 중복 차감하지 않는다.
- 각 시점에 기본·동시점 SPY·비용 24bp·추가 지연 60초·절반 수량, 총 10경로. 현금 0%도 표시한다.
- 동일한 보존 호가 검색/회계 코드를 재사용한다. 빈 구간은 다음 확인된 구간으로만 진행하고,
  최대 15분까지 원천을 조회한다. 결측이면 해당 경로 전체 수익률은 null, 미청산 보유를 지우지 않는다.
- 누락·실패 원천은 보존한다. 실패 요청 자동 재시도, 보간, 유료 구매, 운영 주문은 하지 않는다.
- 기본이 음수거나 현금/SPY보다 못하거나 스트레스가 음수이면 해당 후보를 채택하지 않는다.
  모두 좋아도 6건의 이미 본 표본만으로 실전 승격하지 않고 별도 평가 필요로 남긴다.

## 관리자 표시 계약

`관리자 → 연구 성적 → 단타 진입 비교`. 소스 호가/키/계좌는 배포하지 않고, 검증 CLI가 만든
작은 요약 JSON만 앱 패키지에 포함한다. GET은 읽기 전용이며 수집·백테스트·주문을 실행하지 않는다.
표시 기준은 **마지막 연구 실행 시각**이다. 새 연구 결과를 배포하면 갱신되며 실시간 전략 운영처럼
표현하지 않는다. 거래별 결정 시각·체결 시각·비용 후 손익, 누적 수익률, 미완료 원인과 채택 판단을 제공한다.
원천 부족은 0%로 바꾸지 않는다. 운영 봇과 신규 진입 보류 설정은 그대로 둔다.
