# 관심종목 공식 재무 근거: 제한적 자동 수집

작성: 2026-10-03 · 범위: 국내 관심종목의 읽기 전용 근거 카드

## 경계

- DART `fnlttSinglAcntAll`의 연결 재무제표(CFS)를 공식 `stock_code → corp_code` 매핑으로만 요청한다. 매핑이 없거나 응답의 회사·사업연도·보고서 코드가 다르면 저장하지 않는다.
- 마감 후 핵심 가격·시그널·계좌 스냅샷, 연구 전진 표식, 개인 마감 알림이 완료된 **다음**에 실행한다. 하루 최대 회사 4곳, 요청 8건(올해 같은 보고서와 전년도 비교 보고서)이다. 중복된 사용자 관심종목과 동일 회사 코드는 합친다.
- `013` 자료 없음은 0원으로 바꾸지 않고 관측 상태로 보존한다. 실패는 유형명만 남기고 키나 원문 URL을 로그에 내지 않는다. 실패·중단은 2일, 자료 없음은 7일, 현재 자료는 14일, 전년도 자료는 180일 간격으로 재조회한다. 이 간격은 수집 비용을 제한하는 정책이지 재무 정보의 유효성 보증이 아니다.
- 수집된 응답 원문·정규화 사실은 append-only 별도 DB에 남긴다. 다운로드한 과거 공시도 **오늘 관측한 사실**일 뿐 과거 시점의 PIT 입력이 아니다. 공시의 실제 장중 공개시각은 이 API만으로 검증되지 않는다.
- 관심종목 화면에 매출·영업이익·영업현금흐름·재고의 같은 보고서/같은 단위 비교를 설명한다. 종목 점수, 매수/매도 판정, 주문, 등록 실험, 페이퍼 성과에는 연결하지 않는다.

## 운영 확인

- 관리자 `/api/data-health`의 `financial_evidence_refresh`에서 `not_started`, `missing_credentials`, `no_favorites`, `ok`, `partial_failure`, `collection_failed`를 구분한다. `requested`, `ok`, `no_data`, `failed`, `response_bytes`는 하루 수집량·실패를 확인하기 위한 값이며, 분석 정확도나 서비스 비용 전체를 뜻하지 않는다.
- 관심종목 카드에 비교가 없으면 먼저 종목의 DART 매핑, 올해/전년 같은 보고서의 공시 존재, 수집일과 `no_data` 상태를 본다. 빈 자료를 채우기 위해 임의의 다른 보고서나 개별 재무제표(OFS)를 섞지 않는다.
- DART 키가 없으면 무요청 상태로 남긴다. 수집 오류가 있어도 거래 엔진은 기존 자료만 사용하며, 새 근거가 있다는 식의 성공 메시지를 내지 않는다.

## 다음 안전 관문

1. 운영에서 실제 카드의 원문 링크, 숫자·단위·기간 일치와 요청/바이트 수를 확인한다. 로컬 파일의 성공을 운영 성공으로 간주하지 않는다.
2. 관심종목이 늘 때 실제 API 제한·응답 크기·실패율을 관측해 예산을 조정한다. `013`을 공시 지연과 영구 부재로 혼동하지 않는다.
3. 이 근거가 투자 판단을 개선하는지는 별도 사전등록 실험과 충분한 독립 표본으로 검증한다. 설명력이 좋아졌다는 이유로 가중치·거래 규칙을 바꾸지 않는다.
