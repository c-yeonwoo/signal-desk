2026-10-08 SIA 공개 월간 발표를 독립 산업 근거 후보로 연결했다. 공개 API 응답에서 기간·수치·3개월 이동평균·게시시각을 파서 대조하고, 원문 전문과 유료 WSTS 자료를 저장하지 않는 읽기 전용 카드 및 수집 상한을 구현했다. 피드가 과거 발표도 함께 반환하는 조건을 반영해 가장 최근 발표 한 건만 저장하도록 보강했다. 같은 날 첫 프로덕션 수집은 1/1 성공, 실패 0회, 원장 1건이었고 카드의 기간·금액·단위·비교율·발표일이 SIA 원문과 일치했다. 단, 관리 화면이 작은 응답량을 `0.0 MiB`로 반올림해 판독하지 못하는 표시 결함을 수정 중이며, 수정 배포 뒤 동일 ID와 건수를 재검사하기 전까지 3단계 8점은 열지 않는다. 따라서 **72/100 유지**. 상세 경계와 비교 기록은 [SIA 공개 월간 자료 기록](SIA-PUBLIC-MONTHLY-RELEASE-2026-10-08.md)을 참조한다.

같은 운영 화면에서 연준 G.17은 요청 1/1 성공·2.6 MiB·보존 원문 1건, 첫 ID `267699161d6b39350382a3603d526af269727df60fa972d5f08085b30bc1c010`을 확인했다. #576 배포 뒤에도 건수와 첫 ID는 동일했다. 이는 **10월 새 발표가 아닌 첫 운영 관측**이며, 9월 발표본과 다음 발표본의 숫자·보존 비교 전에는 3단계 8점을 더하지 않는다. SEC는 실제 연락처 미설정으로 요청/원문 모두 0건이며 7점은 계속 닫힌다. 운영 화면의 국내 종가는 10-06 15:45 KST 갱신으로 표시됐지만, 미국 마지막 봉은 509개 중 6개가 뒤처졌고 KB는 21개 대상 중 최신 근거 5개만 남았다. 신선도 부족은 설명에서 제외되고 있으며 이 상태를 전체 데이터 정상으로 해석하지 않는다. 1분 실시간 시세 SSE의 장중 실제 수신은 이 장마감 관측으로 검증할 수 없다.

2026-10-04 KB 신선도 보강은 별도 안전 작업이다. 종목 뉴스 원문 발행시각·수집 성공/실패·요약 생성시각을 구분해 오래되거나 시점 불명의 요약이 현재 기업 소식과 해설에 들어가지 않도록 한다. 이는 데이터 확장 4단계의 DART/연준/SEC 운영 수집·원문 대조·초보자 평가의 완료 증거가 아니므로 **60/100 유지**다. 자동 KB 수집의 기본 OFF도 유지하며, 실제 운영 신선도 개선은 배포 후 대상별 수집 성공과 원문 날짜를 확인해야만 말할 수 있다.

2026-10-04 관심종목 근거 탭과 기사 귀속 게이트도 별도 안전·사용성 작업이다. 제목 주체·계약 역할·매출 분모가 불명확한 검색 결과는 현재 요약에서 제외하며, 일반 뉴스 이벤트는 매매 Decision에서 분리한다. 운영에서 실제 최신 원문이 수집·대조됐다는 뜻은 아니다. 저장소 경로별 사용량 진단은 Railway 용량 원인 확인용이며 삭제 작업이 아니다. **4단계 진행률은 60/100 그대로다.**

운영 표시 확인(2026-10-04, [시그널 화면](https://signal-desk-production-fc75.up.railway.app/?v=531-5#signal)): 펼친 판정 상세에 `자료 모으는 중`과 위 두 분모가 나왔고 등록 헤드라인 백분위는 없었다. 다른 `매수 정밀도 62.4% · 기준선 55.5% · 표본오차 ±10.3%p`가 함께 보이지만 이는 등록 헤드라인 판정이 아니다. 첫 화면의 `아직 알 수 없음`을 수익 검증 완료로 해석하지 않는다. 이 항목의 5점은 **표시 정직성**만의 점수다.

[국내 재무 카드와 보존 DART 원문의 대조](DART-CARD-RAW-AUDIT-2026-10-03.md)는 첫 운영 수집 전에는 코드·합성 테스트만 있어 4단계 7점을 더하지 않았다. 10-06의 두 법인 공식 원문 대조와 재배포 후 재검사로 이 관문을 완료했다.

첫 운영 수집 전 원문 대조의 표본을 `관측된 첫 두 법인`에서 `비교 카드가 성립하는 첫 두 법인`으로 정정했다. 전년 자료 부족 등 제외 이유를 공개하고, 불일치 카드는 제외하지 않으며 보존 오류는 후순위 법인으로 대체하지 않는다. 운영 표본을 보기 전 규칙 변경이므로 결과에 따른 골라내기가 아니다.

[관심종목 근거 이해도 평가 절차](USER-COMPREHENSION-EVAL-2026-10-03.md)는 과업·채점·표본 기준만 고정했다. 실제 초보자 5명 이상의 동일 과업 기록과 오해 추적 전에는 4단계 사용자 이해도 5점을 더하지 않는다.

2026-10-04 운영 관리자 화면에서 #531의 독립 수집 카드가 정상 응답했으나 DART·연준 G.17·SEC는 모두 최근 30일 요청 0회, DART 보존 원문 대조는 0/2개였다. 따라서 2·3단계 수집 점수와 4단계 운영·원문 대조 점수는 올리지 않는다. 전체 진단과 시그널 목록은 처음엔 시간 초과/응답 오류를 보였지만 재확인 시 정상 응답했다. 일시 장애 원인은 특정되지 않았으며 지속 정상성의 증거도 아니다.

2026-10-04 후속 코드 보강: 마감 유지보수의 한 봇 보유 스냅샷 실패가 공식 자료 수집 선행 게이트를 막지 않도록 격리했다. 공식 수집기 3개의 실행 관문과 실패 기록을 회귀 테스트했고, G.17의 요청 없는 사전 조회가 같은 날 실제 요청량 기록을 선점하지 않도록 했다. 이는 **실행 경로의 견고성**일 뿐 운영 수집·보존의 성공 증거가 아니므로 점수는 60점 그대로다.

저장 경로 사전점검은 Railway 볼륨 선언·실제 마운트 관측·앱/원문 DB 경로 포함 여부를 관리자 접힌 카드에 구분해 표시한다. 이 점검이 통과해도 **배포 뒤 원문 생존이 증명된 것은 아니다**. 첫 수집 후 배포 전후의 동일한 원문 ID와 감소하지 않은 건수를 확인해야 운영 보존 점수를 검토한다.

2026-10-04 운영 확인([관리자 운영 상태](https://signal-desk-production-fc75.up.railway.app/?v=536#admin/ops)): #536 배포 뒤 저장 볼륨 마운트와 앱/원문 DB 경로 정합성이 화면에 확인됐다. 앱 DB 부팅 219회·최초 부팅 `2026-08-06T01:12:50+00:00`는 유지됐지만 DART·연준·SEC 보존 원문은 각각 **0건**이다. 세 원천 모두 최근 30일 요청 0회이고 SEC 실제 연락처도 미설정이다. 따라서 이 관측은 저장 위치의 사전조건만 충족하며, 수집·재배포 보존·비용·실패율·원문 대조의 완료 증거가 아니다. 진행률은 60/100 그대로다.
