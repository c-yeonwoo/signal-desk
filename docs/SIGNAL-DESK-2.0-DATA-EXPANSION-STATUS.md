# Signal Desk 2.0 데이터 확장 장부

기준: 2026-10-04 · 범위: **데이터 확장 4단계**, 전체 2.0 제품 로드맵이나 기존 엔진 검증 점수(2026-10-02의 59/100)가 아니다.

완료율은 코드 줄 수나 자료 건수가 아니라 아래 **사전 정의된 산출물 100점** 중 검증된 항목의 합이다. 운영 확인이나 독립 표본을 로컬 테스트로 대체하지 않는다. `판별력 없음`은 검증 결과일 수 있으나, 표본 부족을 해결한 것으로 세지 않는다.

| 단계 | 배점 | 현재 | 완료 증거 | 남은 관문 |
|---|---:|---:|---|---|
| 1. 공식 원천의 안전한 관측·보존 | 25 | **25** | #513: SEC/DART 명시 대상, 신원·기간·단위 검증, 원문/정규화 사실 불변 보관, 과거 데이터의 현재 관측 처리 | 새 원천마다 동일 계약 적용 |
| 2. 관심종목의 검증 가능한 기업 변화 | 25 | **20** | #514: 같은 DART 보고서 전년 비교 카드. #515: 국내 관심종목 하루 4사·8요청, 재시작 후 상한, 결측/실패 구분 | **5점:** 운영에서 실제 카드 숫자·원문·수집량·볼륨 지속성 확인 |
| 3. 시장·업종·기업 근거의 안전한 결합 | 25 | **10** | #516: FRED/ECOS 원천 링크·관측일/조회시각·공개시각 미검증 표시, 키 누출/비정상 응답 방어 | **15점:** 독립 산업 원천 1종의 이용조건·시점 확인 후 읽기 전용 카드(8), SEC 미국 관심종목 비교와 실제 연락처 기반 수집(7) |
| 4. 운영 품질과 투자 가치의 분리 검증 | 25 | **5** | #530의 사전등록 첫 화면 표시를 2026-10-04 운영에서 확인: `아직 알 수 없음`, 실효 12/30(추정), PIT 62/150, 등록 헤드라인 백분위 비노출. 수익 우위가 확인됐다는 뜻은 아님 | 운영 수집 실패율·비용 단서·수정 이력의 실제 누적/보존 확인(8), 원문-카드 수치 표본 대조(7), 사용자 이해도·판단 과정 평가(5) |

**현재 진행률: 60/100 = 60%.** 누락된 40점은 각각 종료 증거가 생길 때만 더한다. 이 숫자는 기대수익률도 정확도도 아니다.

운영 표시 확인(2026-10-04, [시그널 화면](https://signal-desk-production-fc75.up.railway.app/?v=531-5#signal)): 펼친 판정 상세에 `자료 모으는 중`과 위 두 분모가 나왔고 등록 헤드라인 백분위는 없었다. 다른 `매수 정밀도 62.4% · 기준선 55.5% · 표본오차 ±10.3%p`가 함께 보이지만 이는 등록 헤드라인 판정이 아니다. 첫 화면의 `아직 알 수 없음`을 수익 검증 완료로 해석하지 않는다. 이 항목의 5점은 **표시 정직성**만의 점수다.

[국내 재무 카드와 보존 DART 원문의 대조](DART-CARD-RAW-AUDIT-2026-10-03.md)는 버튼·검사 코드가 마련됐지만 실제 운영 수집 2개 기업의 원문 대조 전에는 4단계 7점을 더하지 않는다.

[관심종목 근거 이해도 평가 절차](USER-COMPREHENSION-EVAL-2026-10-03.md)는 과업·채점·표본 기준만 고정했다. 실제 초보자 5명 이상의 동일 과업 기록과 오해 추적 전에는 4단계 사용자 이해도 5점을 더하지 않는다.

2026-10-04 운영 관리자 화면에서 #531의 독립 수집 카드가 정상 응답했으나 DART·연준 G.17·SEC는 모두 최근 30일 요청 0회, DART 보존 원문 대조는 0/2개였다. 따라서 2·3단계 수집 점수와 4단계 운영·원문 대조 점수는 올리지 않는다. 전체 진단과 시그널 목록은 처음엔 시간 초과/응답 오류를 보였지만 재확인 시 정상 응답했다. 일시 장애 원인은 특정되지 않았으며 지속 정상성의 증거도 아니다.

2026-10-04 후속 코드 보강: 마감 유지보수의 한 봇 보유 스냅샷 실패가 공식 자료 수집 선행 게이트를 막지 않도록 격리했다. 공식 수집기 3개의 실행 관문과 실패 기록을 회귀 테스트했고, G.17의 요청 없는 사전 조회가 같은 날 실제 요청량 기록을 선점하지 않도록 했다. 이는 **실행 경로의 견고성**일 뿐 운영 수집·보존의 성공 증거가 아니므로 점수는 60점 그대로다.

저장 경로 사전점검은 Railway 볼륨 선언·실제 마운트 관측·앱/원문 DB 경로 포함 여부를 관리자 접힌 카드에 구분해 표시한다. 이 점검이 통과해도 **배포 뒤 원문 생존이 증명된 것은 아니다**. 첫 수집 후 배포 전후의 동일한 원문 ID와 감소하지 않은 건수를 확인해야 운영 보존 점수를 검토한다.

2026-10-04 운영 확인([관리자 운영 상태](https://signal-desk-production-fc75.up.railway.app/?v=536#admin/ops)): #536 배포 뒤 저장 볼륨 마운트와 앱/원문 DB 경로 정합성이 화면에 확인됐다. 앱 DB 부팅 219회·최초 부팅 `2026-08-06T01:12:50+00:00`는 유지됐지만 DART·연준·SEC 보존 원문은 각각 **0건**이다. 세 원천 모두 최근 30일 요청 0회이고 SEC 실제 연락처도 미설정이다. 따라서 이 관측은 저장 위치의 사전조건만 충족하며, 수집·재배포 보존·비용·실패율·원문 대조의 완료 증거가 아니다. 진행률은 60/100 그대로다.

첫 수집 전 경로 검토에서 DART 기업코드 ZIP 조회의 **빈 결과가 프로세스 종료까지 캐시되는 문제**를 발견했다. 한 번의 일시 실패로 관심종목 수집 대상이 계속 0이 될 수 있어, 성공한 매핑은 기존 DB 24시간 캐시에서 읽고 빈 결과는 30분 후 재조회하도록 보강했다. 매핑이 비었을 때는 `수집 완료·요청 0회` 대신 `DART 기업코드 조회 실패`로 표시한다. 운영 요청·원문 성공 확인 전에는 이 보강도 점수에 반영하지 않는다.

## 다음 순서와 차단 조건

1. #515 운영 배포 후 마감 유지보수에서 `financial_evidence_refresh` 상태와 1일 요청 예산을 확인한다. 다음 정상 국내 마감 전에 네트워크 수집 성공을 주장하지 않는다. 카드의 현재/전년 원문 접수번호·단위·기간을 2개 기업 이상 대조한다.
2. 산업 근거 후보는 **출처의 대표 범위와 이용조건**을 확인한다. [TSMC 월매출](https://investor.tsmc.com/english/monthly-revenue/2026)은 파운드리 한 회사의 연결 매출이며 한국 메모리·장비 업종 전체의 매수 신호가 아니다. 2026-10-03 확인 화면에서 9월 값은 아직 비어 있었다. [SIA 글로벌 반도체 판매](https://www.semiconductors.org/global-annual-semiconductor-sales-increase-25-6-to-791-7-billion-in-2025/)는 WSTS 자료의 3개월 이동평균으로 설명된다. 이것도 개별 종목의 선행 수익률로 전용하지 않는다. TSMC 사이트의 자동 접근 조건은 아직 확인되지 않아 크롤러를 배포하지 않는다.
   - [연준 G.17 `G3344`](INDUSTRY-PULSE-G17-2026-10-03.md)는 공식 원문을 2026-10-03 로컬에서 시험 수집했고, 월간 미국 산업생산이라는 범위를 분리했다. 읽기 전용 카드·보존 코드는 **운영 확인 전**이며 3단계의 8점을 아직 더하지 않는다.
3. 미국 [SEC companyfacts API](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)는 회사별 공식 XBRL 사실을 제공한다. `SEC_CONTACT_EMAIL`에 실제 운영 연락처가 없으면 자동 수집을 열지 않는다. 회사/티커-공식 CIK 매핑과 정확히 같은 태그·단위·보고기간 비교, 정정본 선택 기준을 먼저 테스트한다.
   - [기존 EDGAR 연락처 관문](SEC-EDGAR-CONTACT-GUARD-2026-10-03.md)은 예시 주소를 실제 신원으로 쓰지 않게 하고 기존 캐시 보존을 검증한다. 운영의 실제 연락처·새 비교 카드가 없으므로 3단계 SEC 7점은 여전히 대기다.
   - [미국 관심종목 SEC 비교 설계](SEC-WATCHLIST-FINANCIAL-CHANGE-2026-10-03.md)는 코드·테스트 단계다. 운영 연락처가 미설정인 동안 실제 요청은 0이며, 테스트의 예시 기업·금액을 운영 증거로 세지 않는다.
4. [FRED 관측 API](https://fred.stlouisfed.org/docs/api/fred/series_observations.html)의 기본 조회는 현재 알려진 과거값이다. 역사적 의사결정 자료에는 [ALFRED vintage](https://fred.stlouisfed.org/docs/api/fred/realtime_period.html)와 실제 공개시각·입수시각을 별도 검증해야 한다. 현재 #516의 표시 개선을 PIT 적격 증거로 승격하지 않는다.

기존 잠금 유지: `pit-8factor-rank3-hold5-final`의 문턱 **99.15%**, PIT **150**, 실효 **30**, R11–R16 연구 전용. 2026-10-04 달력 정정: **10-05는 개천절 대체휴장일**이므로 10-02의 PIT 62에서 하루 한 세션씩 정상 적재될 때 68번째 PIT의 가장 이른 날은 **10-14 마감**이다(10-09 한글날도 휴장). interim은 실측 요건 전에는 실행하지 않는다. 날짜는 예상일일 뿐, 요건을 낮추거나 실제 누락을 추정치로 채우지 않는다. 데이터 확장 진척이 이 판정 관문을 열지 않는다. 수익 우위가 입증되지 않으면 점수·가중치·주문을 바꾸지 않고 설명·관측의 가치만 평가한다.
