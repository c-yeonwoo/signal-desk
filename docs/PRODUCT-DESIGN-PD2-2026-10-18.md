# SIG-26 · 실제 종목 작업대 적용

기준 main `2bdb70cc11c7c21840c1a6ac63e19a87840bbd2d`. PD1 시안을 기존 서비스에 연결한다. 시안에서 생략한 **가격선·시그널 점수선·매수/매도 표시·툴팁·간단/추세/자세히 모드**는 모두 유지한다. 생성 이미지/예시 가격/하드코딩 순위를 운영으로 옮기지 않는다.

## 고정 범위

- 기존 API·순위·점수·관점 필터·원천·주문·연구 계약은 변경하지 않는다.
- 실제 목록에 가격·등락·후보 상태를 표시하고 기술 점수는 보조 정보로 둔다. 별도 SSE 현재가는 판정 가격과 분리한다.
- 모바일 상세를 표 안에 옮기지 않고 목록/상세 왕복한다. 검색·정렬·선택·포커스·차트 리사이즈를 보존한다.
- 상세는 이름/가격/시각 → 후보 범위/기록상 가격 변화 → 기존 전체 차트 → 기업 근거/보유 맥락 순서다. 원문 미확인을 악재 없음으로 바꾸지 않는다.
- 관심 탭의 기존 원문·확인 시각·미확인 정보와 종목 상세 이동을 보존한다.
- 조회 실패에는 재시도, 가격 결측에는 판정 보류, 지연에는 지난 판정을 표시한다. 같은 종목 재요청도 이전 응답이 덮어쓰지 못하게 한다.

## Direction contract

**THESIS:** 비교할 수 있는 목록과 시그널 흐름을 빠짐없이 보존한 상세.

**OWN-WORLD:** 실제 Pretendard·중성/indigo 토큰 계승. 기존 앱 셸/다른 메뉴는 바꾸지 않는다.

**STORY:** 종목 비교 → 가격/판정 시각 → 가격과 시그널 흐름 → 근거/미확인 → 보유 진단.

**FIRST VIEWPORT:** PC 340px 목록/상세, 모바일 한 화면 왕복. 차트는 기존 실제 데이터를 그린다.

**FORM:** 합의 시안의 한정 적용, 새 브랜드/seed 선정 없음.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 완료 전 확인

실제 렌더 PC/모바일 묶음 검수, 경계 동작 테스트, 독립 코드/마감 리뷰, 정확한 PR HEAD CI, 머지를 구분해 기록한다. 배포 확인·소유자 수용은 확인 없이 완료로 표시하지 않는다. 성능/수익 개선을 디자인 변경의 성과로 주장하지 않는다.

## 구현·검수 증거

- 실제 앱 HTML/JS에 격리된 합성 API를 연결했다. 서비스 모듈·환경파일·계좌·원천 수집·주문은 로드하지 않았다. [PC](../.impeccable/review/pd2/desktop.png), [모바일 목록](../.impeccable/review/pd2/mobile-list.png), [모바일 상세](../.impeccable/review/pd2/mobile-detail.png), [출처](../.impeccable/review/pd2/captures.json)는 운영 시세의 증거가 아니다.
- 실제 브라우저 13개 기록: 정상/지연/결측/차트·근거 오류/재시도 포커스/목록 실패/빈 검색/미국 통화/관심 원문→상세 이동/관심 저장·복귀/추세·자세히 모드 등. 최초 관심 저장 포커스 손실은 발견 기록을 지우지 않고 복구 후 성공 기록을 덧붙였다. 기록은 회사 runtime의 `pd2/browser-checks.json`에 보존했다.
- 관련 테스트 **67 passed**(11파일). 실제 JS의 새 응답·동일 캐시·같은 종목 재요청 경합·결측/지연·모바일 왕복과 ECharts option의 3모드 가격/점수/구간/B·S/툴팁/이동평균/RSI/MACD/수급을 확인했다. 기존 기업 근거·보유 손실·출처/HTML 방어도 포함한다. 스크립트 구문과 diff check 통과.
- 독립 리뷰에서 개요 정보 소실, 요약 재조회로 상세 정보 소실, 모바일 목록 강제 이탈을 찾아 수정했다. 상세는 같은 캐시일 때 보존하고 새 응답일 때 현재 화면/포커스를 유지한 채 다시 조회한다. 마감 리뷰 판정은 ship이며 일반 독립 리뷰어로 전용 유형을 대체했다. 리뷰어가 브라우저·pytest·CI를 직접 실행한 것은 아니다.
- Impeccable 검사에서 단일 HTML 전체의 기존 dialog/온보딩/클리핑/장식 등 경고가 남았다. 전체 경고 0이나 접근성 인증을 주장하지 않는다. 이번 작업대의 불필요한 overflow clipping은 제거했고 범위 밖 공통 정합은 PD5/PD6에서 다룬다. 전역 DESIGN.md를 부수적으로 재작성하지 않는다.
- 핵심 차트 계산/그리기 본체, API·엔진·순위·연구·주문은 변경하지 않았다. PD1 가격만 표시한 예시가 운영 기능 축소로 이어지지 않도록 실제 전체 차트를 인수 조건으로 고정했다.
- 첫 전체 CI에서 기존 표 열 구현에 묶인 검사2개·글자 척도·옛 손실 HTML 식별자 검사가 실패했다. 표를 되살리거나 검사 허용치를 늘리지 않고 실제 새 구조/손실 구분 계약으로 갱신했다. 제목은 기존24/22px 척도로 복원하고 일반 두께는 `normal`로 표현했다. 추가 검수는 관련 **77 passed**이며 전체 CI는 새 HEAD로 다시 확인한다. 척도 오류 수정 뒤 최종3캡처를 갱신했다.

진행: SIG-26 구현·로컬 검수 완료. 정확한 PR HEAD CI·머지·운영 배포 확인은 전달 기록에 따로 남긴다. 소유자 수용은 아직 미확인이다. PD1의 완료1/6을 구현만으로 수용2/6으로 올리지 않는다. 통합 **40% 유지**.
